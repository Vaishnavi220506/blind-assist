# 原地四步采集：相机 + ToF

固定相机和 ToF，拿一本书或纸盒，在眼前方便的背景完成四段。录制共 150 秒，
每段之间等你准备好再继续，不需要量尺、走廊、键盘打点或第二个人。

从仓库根启动 `pwsh -File research/active/hardware-bringup/simple-capture.ps1`，
打开 <http://127.0.0.1:8768/>。页面按已知设备序列号预选 XIAO / Atom 端口；
只枚举不采集，点击预览或开始才连接设备。相机支持既有 Atom USB-OTG JPEG 固件，
或 Wi-Fi 固件；ToF 使用 USB 8×8×16 CNH。若设备或固件不符会留下错误记录，不自动刷写。

Wi-Fi 相机启动时增加 `-CameraUrl 'http://<相机局域网IP>:81/stream'`，页面会显示
“Wi-Fi 相机”，不打开相机 USB 串口。相机需连接 2.4 GHz；电脑可以在同一路由器的
5 GHz 网络，前提是两侧互通。相机 IP 以当次配置回执/发现结果为准。

可先点“先看相机 + ToF 预览”，最多 5 分钟，不推进正式步骤；点击开始第一段时
先结束预览并释放串口，再启动正式录制。预览留证单独保存在
`artifacts.local/hardware-bringup/previews/`，不能当作四段动作已经完成。
若 Atom 运行手机演示的 Wi-Fi 固件，USB 相机请求会超时，应使用上面的 Wi-Fi 入口。
Wi-Fi 采集保留 JPEG、设备帧序号/时间戳和 HTTP 解码后的 multipart 原始字节，
与 USB ToF 一起保留主机接收时间；没有据此声称曝光同步或空间对齐。

1. 填物体名字（不知道可留空），固定设备；点开始，保持原有背景 30 秒。
2. 点下一段：放入物体、停约 10 秒、拿走、停约 10 秒；重复两次。本段 60 秒。
3. 点下一段：同一物体缓慢左右、前后移动，30 秒。
4. 拿走物体，点最后一段：恢复背景并静止 30 秒。

页面显示相机最新帧、ToF 原始区序网格、所选区 CNH 和倒计时。每段自动保存并停下；
准备期间不采集。提前结束会保留已录内容，并报告实际完成段数，不冒充四段完成。
关掉网页不会中断当前有界分段，但不会自动开始下一段。

输出在 `artifacts.local/hardware-bringup/captures/simple-<时间>-<编号>/`：
每次尝试独立保存 `camera/`、`tof/` 的原始数据、时间戳、图片及收据；根目录保存
`session.json`、`notes.md`、`guide-summary.json`。失败重试保留旧尝试。
结束后补记是否碰动传感器、漏做了哪个动作即可；距离未知就保留未知。

这次只看数据连续性、物体引起的变化与背景恢复。分段标签表示操作者打算执行的动作，
相机可辅助核对实际动作，但主机接收时间不是曝光同步；网格尚未对齐相机，不输出警报。
CNH 柱图随当前帧缩放，不能仅凭柱高比较强弱；UNKNOWN 不是没有障碍。

服务只监听本机。完成页点“关闭本地采集服务”，或在启动终端 Ctrl+C，可收尾并释放资源。
