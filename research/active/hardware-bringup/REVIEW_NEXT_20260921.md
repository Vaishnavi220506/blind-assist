# 硬件模块审视与下一项，2026-09-21

结论：已打通台架采集样机，尚未完成可供融合使用的观测模块。现阶段保留 Atom
和 XIAO+ToF 分体方案，电脑继续作为采集主机；没有依据要求更换硬件或购买量具。
本次审查只读取源码、已存日志摘要及本地手册，没有新采集、重启、刷写或调参。

## 按模块判断

| 模块 | 已验证的范围 | 剩余缺口与安排 |
|---|---|---|
| Atom RGB | VGA JPEG，多段短采集可解码且请求序号连续 | 保留当前 USB-OTG 固件；长时间运行、曝光时间、姿态/镜头标定未验证 |
| XIAO + ToF | 距离和 4×4×24 CNH 约 5 Hz 读出，接近/远离有响应 | status=5 不能单独保证可信物距；近零值静止也可复现，优先补诊断 |
| 主机采集 | 原始字节、状态、序号、哈希、回放、最近接收时间对应 | 首尾部分 JSON 已显式记录；仍为开发工具，无运行时失效/陈旧数据接口 |
| 相机/ToF 对应 | 固定在一起，两路同时采集 | 原始 zone 朝向、共同视野、内外参、曝光时钟映射尚未建立 |
| 装配/供电 | USB 供电下已有多段输出 | 相对姿态刚性、线材拉力、板载稳压余量和便携供电未验收；当前不随意改 VCC |
| 手机/应用 | 原项目有旧 Atom+单区 ToF4M 适配 | 本路线的 USB JPEG 与多区 CNH 未接手机；旧适配不能直接当作已兼容 |

相机约 25–28 张/秒、ToF 约 5 帧/秒来自已有短采集，不是长期性能保证。
ToF 约每 200 ms 一次观测，重复绑定到多张 RGB 不会提高 ToF 的测量频率。
主机接收时间差不是曝光同步误差；可疑/缺失距离不能自动成为“无障碍”。

## 为什么下一项是补诊断

近零异常见 [手持与静止记录](LOCAL_HANDHELD_20260921.md)。已有原始串口与解析对象
一致性核对，不能用修改绘图解释它。CNH 显示部分异常区域仍有后段峰，但不足以
认定两个物体、选定根因或直接替换距离。

代码审查发现以下信息缺口：

- [固件](firmware/tof_cnh/tof_cnh.ino)目前只输出距离、目标状态/数量及 CNH；供应商
  `VL53LMZ_ResultsData` 已包含信号强度、环境光、range sigma、SPAD 数和反射率估计。
- 目标排序没有显式设置或读回。本地 UM3183 Rev 7 §4.9 写明默认 Strongest，但手册
  默认值不等于本机读回值；不能先假定当前为 Closest，再盲目切换模式。
- [平台配置](firmware/platform.h)每区只取一个目标；下一项先保持此配置，避免同时
  改变输出形状、带宽和目标排序。多目标以后按诊断结果决定。
- ULD 对距离进行 `/4` 并将负值置零，现有串口数据在转换之后。应保留同一测量块
  转换前的有符号距离，与最终值并列，检查换算链；不修改供应商的测距算法。
- 当前启动配置仅在 boot 输出，后来打开串口会错过。诊断协议应能主动查询固件
  标识及实际设置，并保存到本次采集证据，避免依赖文件名推断设备状态。

## 唯一立即下一项：诊断固件与一次对照

交付一个独立诊断候选，保留现有可恢复版本。准备源码、编译和主机解析后，再执行
已选定 XIAO 的备份/固件身份核对及上传；不要把 Atom 与 XIAO 的相同 USB VID 当作身份。

诊断内容：实际分辨率、频率、积分时间、ranging mode、target order；每区距离、状态、
目标数、信号/环境光、range sigma；同帧转换前距离与 CNH。配置查询放在合适阶段，
避免读取 DCI 覆盖用于提取当前测量块的 `temp_buffer`。保留旧字段与未知状态。

维持当前 4×4、5 Hz、20 ms、单目标及 CNH 配置，不改有效性阈值，不改目标顺序，
不同时重装器件或做 Xtalk 标定。取得一次静止对照，目标是定位信息链而非调出漂亮曲线。

验收与停止点：新字段来自同帧且形状/单位明确；转换可核对；配置有实际读回；
传输错误如实保留。若定位换算/配置缺陷，修复该处并做一次回归；若近端回波仍存在，
将状态定为“设备侧/光学原因待区分”，下一步只选一个光学装配对照。若该段没有复现，
记录未复现，不宣布修好，也不无限延长采集。不会仅靠新字段承诺一次查明全部根因。

## 后续顺序

1. 给下游明确的距离质量、UNKNOWN、数据年龄和失联状态；保持原始值可追溯。
   暂不把 `min(distance_mm)` 直接变成告警。
2. 建立可回放的 RGB+ToF 联合查看入口，先验证 zone 朝向与共同视野，再做所需的
   时间/空间标定。无标定时并排显示，不把网格伪装成准确的像素覆盖。
3. 手机先接收、显示、记录及处理断连，再接实时融合。届时以当前协议明确实现适配，
   并一起验证供电与持续运行；不继承旧单区 ToF4M 的兼容声明。

阶段目标是可录制、可回放、能表达失效的硬件观测模块。近零诊断有界推进；记录和
显示能力不必等到所有异常消失，但告警/融合不能默默把可疑值当作可信距离。
绝对精度标定留待有参考量具时进行，不阻塞当前工程诊断。模拟研究保持独立。
