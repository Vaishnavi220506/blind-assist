## Supervision and the only scientific difference

Rasterize first hits of saved collision AABBs with native camera pose at native
RGB resolution, including visible continuous portions never sampled by ToF.
This is collision-surface supervision, not a complete Unreal depth image.
No saved hit means UNKNOWN and zero loss weight. Model forward accepts only
public MZ140 image/sparse inputs, never IDs, owners, masks or labels.

Both losses supervise exactly the same known pixels. Pixel arm sums L1 over
the4frames and divides by their total known-pixel count. Balanced arm partitions
each frame into known non-target pixels within8px of the target silhouette and
all remaining visible owner surfaces. Each nonempty visible object surface
(including env0 and rod shape1) first receives its mean L1; average these means,
then average that surface term and the separately normalized ring term equally.
Average frames equally. If the ring is empty, use only the surface term.
Ring pixels are removed from owner masks, so no double-counting. This is visible
object-surface normalization, not separate cuboid-face normalization. The
pre-existing8px diagnostic defines this local neighborhood; no class weights.
