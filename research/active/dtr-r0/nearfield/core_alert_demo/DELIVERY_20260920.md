# 几何告警实验台：工程交付

冻结强阈值与非递归一帧保持已整理为统一观测接口，并接入可解释离线回放。此交付没有改变算法、工作点、实验结论或 App 默认行为。

## 使用入口

构建输出位于仓库 `artifacts.local/work/ba-core-alert-demo-20260920/site/`。双击 `launch_demo.cmd`，或打开同目录 `index.html`；移动演示时保留整个文件夹。具体操作见 [使用说明](README_使用说明.md)。

页面包含三组完整回放，共108个布局、1296帧。现场回放联动 RGB 展示、64区观测、区域投影、完整测距支持区间、俯视/侧视图、分数因子、真实强证据与保持状态、四条真值/告警时间轨道。工作原理页解释因果链；全量结果页分别展示 Core、Boundary、全部布局的三种固定读出。

导览同时保留保持收益、通道外消警、旧 HEAD 首报延迟和 Boundary 漏报。RGB 和可选紫色真值轮廓只用于展示；推理接口不接收这些信息。顶部统计始终取当前数据集的完整 Core 分母，不随目录筛选变化。

## 一致性和检查

- `CoreAlertPolicy.step()` / `reset()` 复用冻结评分和决策。5个策略测试通过，覆盖保持不可递归、切片段/非连续采样复位等行为。
- `build_data.py` 重新计算全部1296帧并核对三种告警、当前 UNKNOWN、原始支持和分数；三组完整指标一致。来源封存记录与观测/RGB哈希通过核对。
- 新验证组的逐区评分因子来自相同冻结代码重算，原封存结果只保存标量和原始支持；其余两组另核对已保存的逐区因子。详见输出上一级 `build-receipt.json`。
- `test_presentation.cjs` 核对全部帧的显示类别、真值与告警分离、最大分数区选择，以及27组范围/方法指标和误报段数，全部通过。
- Chromium 本地 HTTP 浏览器检查通过：四个导览、上一/下一帧、时间定位、2倍播放到片尾、循环与暂停、数据集/场景切换、HEAD与OUTSIDE组合筛选、缺失测距、手动/自动选区、空间范围、真值轮廓、原理页、Core/Boundary结果表。桌面1440像素及约568像素窄窗已查看实际渲染；浏览器未记录脚本警告或错误。
- 已修复导览文字在切帧后沿用旧帧解释的问题，并重查切帧后的中性说明。
- 直接 `file:///` 导航被自动化浏览器 URL 策略阻止，未绕过。因此离线入口的依赖/相对路径已静态检查，但默认浏览器双击启动未在自动化中验收。可选 `serve_demo.py` 本地 HTTP 入口已实际验收。
- 仓库结构检查因三个已有共享状态文档超预算而未通过：`PROJECT_STATE.md`、`CURRENT_DECISION.md` 和路由 `CURRENT.md`。本交付未修改这些文件，演示的独立检查不受影响。

这是一项已有结果的工程展示。新验证组 Core 的74/10/0及旧迁移组76/9/2都原样保留；旧首报延迟没有被修好，新验证组 Boundary 仍只有4/12事件检出。保持没有补充当前帧空间观测，UNKNOWN不会因提醒而消失。受控回放不能作为实时硬件、自然场景、人的反应余量或退出后拖尾验证。
