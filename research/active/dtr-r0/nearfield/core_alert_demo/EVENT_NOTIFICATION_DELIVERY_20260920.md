# 事件提示调度：保留检测输出，连续告警只提示一次

2026-09-20。工程改动，仅使用已有封存输出回归；没有新采集、训练、阈值调整或算法晋升。

演示的“现场回放”增加默认关闭的“事件提示音”。开启后，每段连续 `alert=true`
首次申请一次120毫秒本地短音。持续告警不重复；首个 `false`、暂停、跳转、切换
片段、隐藏页面或关闭声音均取消待播放和正在播放的声音。音频解锁延迟返回时，
必须再次通过事件令牌校验，过期请求无法播放。无语音服务或网络音频依赖。

同位置暂停再继续不重报；跳转、循环或片段切换重置观看历史。重新开始观看时，
当前已有告警也可提示一次。逐帧查看不发声；告警中途开启声音等待下一段。
通知段来自连续检测输出，不进行物体身份关联、跨间断合并或额外保持。
