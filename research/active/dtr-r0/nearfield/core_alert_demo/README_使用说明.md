# BlindAssist · 空间感知演示台

双击同目录的 **launch_demo.cmd**，或用浏览器打开 **index.html**。
无需安装依赖，不联网。请保留整个文件夹：页面、demo-data.js、extra-data.js 和 assets 缺一不可。

## 建议的演示顺序

从“场景列表”选择 RGB 缩略图，打开完整片段。标题显示当前数据集名称，目录保留全部符合筛选的场景。City Sample 集合可用时默认展示它：Big City 五处位置，加上 Small City 一处位置，共两张原生地图。每段说明和运动标签区分接近后退开、横向经过；这不是六个独立城市，也不是实时设备画面。

“播放全部”按当前数据集与筛选播放，播完最后一段自动停止；也可暂停、逐帧定位或停止导览。跨片段不会继承另一场景的历史。侧栏缩略图可随时打开任一完整片段。

默认1×原速。播放器提前解码当前片段并预取下一段开头，最多保留32张解码图片；下一帧就绪后才同时切换图像和数据。短暂等待保留当前完整帧，不逐帧清空画面；真正较长的读取或缺失文件仍会提示。原始采样间隔仍是0.2秒，没有生成插值观测或视频中间帧。

原有机制导览位于“回放”下方的“数据范围与讲解示例”，展开即可访问：

1. 点击“① 保持补帧”。当前帧是弱支持，但上一采样为真实强证据，因此延续一帧。
2. 点击 ToF 网格中的任意一区，联动查看画面中的位置、测距区间、俯视/侧视支持，以及评分因子。可用“跟随最大分数”返回最大几何分数所在区。
3. 逐帧播放，观察“当前强证据”和“仅保持”的区别。下方时间线可以直接点击定位。
4. 打开“工作原理”，解释完整区域与测距区间怎样形成几何分数，以及保持为什么不能递归续期。
5. 依次查看“旧首报延迟”和“边界漏报”。这些不足保留在数据中，没有用演示策略隐藏。
6. 在“评估结果”切换 Core / Boundary / 全部，查看三个完整数据集的对照结果。

快捷键：焦点不在按钮、输入框或下拉框时，空格播放/暂停，左右方向键逐帧。
暂停、跳转、数据集切换均显示原始采样历史对应的冻结结果；不会把上一次观看的帧当成算法的上一帧。

## 事件提示音

在“回放”的播放条下开启“事件提示音”，播放时每段连续告警只发出一次本地短音（120毫秒），保持帧不会重复提示。默认关闭，不使用语音或网络服务。

检测输出首次变为告警时申请提示，首个非告警采样到达时取消尚未播放和仍在播放的声音。暂停、切换页面、隐藏页面、关闭声音也会取消；同一位置暂停后继续不会重复。手动定位、切换片段和循环开始会重置观看历史，重新播放时若当前已有告警，会提示一次。逐帧查看本身不发声。在连续告警中途开启声音会等待下一段。

页面的逐帧告警、UNKNOWN和统计完全不变。这里的“段”是检测输出连续为真的区间，不代表识别了同一个物体；断续告警仍可能多次提示。退出以检测输出为准，不能消除检测器本身的拖尾。浏览器音频不可用时仍可查看全部回放。

已有24段完整事件的封存输出只用于工程回归，未加入本页面原有成绩分母。核查结果见源码目录的 `EVENT_NOTIFICATION_DELIVERY_20260920.md`。

## 界面信息怎样理解

- 画面上的绿色网格是名义45° ToF视场，RGB画面视场为100°；网格不是整张图像的8×8划分。
- 选择一区后，黄色范围代表区域视锥与完整测距区间的空间支持，不能解释成真实障碍形状。
- “评估真值轮廓”默认关闭。开启后紫色虚线来自评估几何，只作对照，不参与告警。
- 几何分数不是碰撞概率。它等于深度重叠占比与区间内平均角域重叠的乘积，帧级读出取可能相交区的最大值。
- 确定支持直接提醒；其余原始支持要达到固定强阈值0.4071309640537889。
- 仅上一相邻0.2秒采样的真实强证据可以保持一帧。保持不能刷新保持状态。
- UNKNOWN可以与提醒并存；未提醒不代表通道畅通。
- “数据范围与讲解示例”中的原有评估统计始终对应当前数据集的完整Core布局，不随场景筛选改变。Boundary另行报告。
- 新增动态集合标为“机制演示 · 未标注”，没有评估真值，不显示 TP/FP/TN/FN、准确率或误报统计，也不进入“评估结果”。实际提醒与UNKNOWN仍原样展示。

展示画面采用原生材质的1920×1080 beauty渲染。用于传感器代理的RGB与原生轴向深度仍为640×360；三种输出使用同一相机姿态、同一100°水平视场。提高展示清晰度不会把传感器输入变成1080p，也没有更换告警算法。

相机按预定姿态逐个设置、等待场景稳定后采样。页面每0.2秒一个时间标签，24帧覆盖0.0–4.6秒；它是分步姿态回放，不是引擎实时运动记录、24fps视频或实测处理时延。片段之间独立重置历史，不生成中间观测。

这些新增场景没有障碍事件评估真值，只展示实际观测驱动的冻结策略响应；不能把提醒称为命中、把未提醒称为正确拒绝，也不并入下方原有成绩。

## 可选本地服务器

本页面通过本地脚本载入完整数据，没有fetch/CDN，正常情况下可直接打开。
若浏览器或企业策略限制本地文件，可在安装Python的电脑运行：

```text
python serve_demo.py --browser
```

服务器仅监听本机127.0.0.1，默认选择空闲端口。按Ctrl+C关闭。
Python仅用于这个可选预览方式，一键离线演示不依赖Python。

## 工程复现

源码位于 `research/active/dtr-r0/nearfield/core_alert_demo/`。
`policy.py` 提供统一 `CoreAlertPolicy.step()` / `reset()`；API只接受观测与时间线，不接受真值、BODY/HEAD或布局类别。
`build_data.py` 从原始64区观测重新执行冻结策略并核对封存输出，然后才加入评估标签。
`build_site.py` 装配页面。City Sample 的采集入口、分辨率与来源收据另见 [交付说明](CITY_SHOWCASE_DELIVERY_20260920.md)。构建收据位于上一级目录，记录数据来源、哈希与完整逐帧一致性。

浏览器只播放已经计算并核对过的因果输出。它不会从真值、显示颜色或四舍五入后的分数重新推断报警。

## 空间感知演示台与动态图

在回放点击“放大视图”，收起目录并放大场景，主画面保持原始 16:9 比例，几何图表紧随播放条显示；“显示目录”恢复目录。

- 空间支持图：区域视锥与测距区间形成的支持体，可调整视角和 4.2/9 m 视窗、点击选区。它不是点云或障碍物重建；裁剪仅影响显示。
- 64 区时间热图：切换测距/几何分数，拖动选区或点击已经播放的格子定位原始帧。缺失返回保留斜纹，未播放历史留白。
- 证据曲线：最大几何分数、有效返回区占比、可能相交区占比随回放更新。固定阈值只对应分数曲线，占比不是危险概率。
- 状态变化记录：点击最近三次变化，回看当前强证据、仅一帧保持与未触发提醒的对应采样。

新增图表只使用当前及过去的观测和封存决策，图像解码完成后一起更新；没有额外网络依赖或持续装饰动画。切换片段重置图表历史，跳回旧帧撤去其后的曲线。折叠的“逐区参数与完整时间线”仍保留全片段评估。

此前版本工程检查：1488 帧图表数据与空间支持检查、1296 帧/27 组原统计一致性、192 帧高清巡游浏览器回归；2×播放期间未观测到加载遮挡、空白画面或图像/帧号错位。1920/1440/568/375 像素宽度无横向溢出。这些浏览器结论仅适用于当时版本，不覆盖下述样式调整；也不是硬件实时性能评估。

## 界面组织（2026-09-21）

采用浅色工作区、深色场景与观测视图。场景列表直接使用数据集名称，回放页使用当前场景名称；无宣传标语、装饰性英文标题或重复首屏大图。导航、控件、数字排版与间距使用统一规则。

在窄屏下，“场景目录”按钮展开数据集和场景选择，默认将空间留给当前内容。回放的 RGB、告警解释与下方“传感器观测”共用同一时间及选区；图表不平滑或补造观测。空间图标签加大，评估结果表格在自身容器内横向滚动。

设计参考与取舍见 [界面参考](UI_REFERENCES_20260921.md)。本版已在内置浏览器检查 1440 px 桌面和 375 px 窄屏：场景列表、回放、原理与结果导航、目录展开/关闭、数据集切换、播放与时间定位均完成抽查；一帧保持示例的图像、时间热图及分数曲线对应同一采样，页面无横向溢出，控制台未见警告或错误。此为工程抽查，不是对所有设备的视觉或性能保证。

1296 个评估帧、192 个演示帧、27 组统计及观测图表、图像切换、事件提示音回归检查通过；算法、原始数据和历史研究结论未改变。
