# BlindAssist · 几何告警实验台

双击同目录的 **launch_demo.cmd**，或用浏览器打开 **index.html**。
无需安装依赖，不联网。请保留整个文件夹：页面、demo-data.js、extra-data.js 和 assets 缺一不可。

## 建议的演示顺序

先从“场景画廊”选择真实 RGB 缩略图，打开完整片段。City Sample 集合可用时默认展示它：Big City 五处位置，加上 Small City 一处位置，共两张原生地图。每段说明和运动标签区分接近后退开、横向经过；这不是六个独立城市，也不是实时设备画面。

“连续导览全部片段”按当前数据集与筛选播放，播完最后一段自动停止；也可暂停、逐帧定位或停止导览。跨片段不会继承另一场景的历史。侧栏缩略图可随时打开任一完整片段。

原有机制导览仍在“现场回放”：

1. 点击“① 保持补帧”。当前帧是弱支持，但上一采样为真实强证据，因此延续一帧。
2. 点击 ToF 网格中的任意一区，联动查看画面中的位置、测距区间、俯视/侧视支持，以及评分因子。可用“跟随最大分数”返回最大几何分数所在区。
3. 逐帧播放，观察“当前强证据”和“仅保持”的区别。下方时间线可以直接点击定位。
4. 打开“工作原理”，解释完整区域与测距区间怎样形成几何分数，以及保持为什么不能递归续期。
5. 依次查看“旧首报延迟”和“边界漏报”。这些不足保留在数据中，没有用演示策略隐藏。
6. 在“全量结果”切换 Core / Boundary / 全部，查看三个完整数据集的对照结果。

快捷键：焦点不在按钮、输入框或下拉框时，空格播放/暂停，左右方向键逐帧。
暂停、跳转、数据集切换均显示原始采样历史对应的冻结结果；不会把上一次观看的帧当成算法的上一帧。

## 界面信息怎样理解

- 画面上的绿色网格是名义45° ToF视场，RGB画面视场为100°；网格不是整张图像的8×8划分。
- 选择一区后，黄色范围代表区域视锥与完整测距区间的空间支持，不能解释成真实障碍形状。
- “评估真值轮廓”默认关闭。开启后紫色虚线来自评估几何，只作对照，不参与告警。
- 几何分数不是碰撞概率。它等于深度重叠占比与区间内平均角域重叠的乘积，帧级读出取可能相交区的最大值。
- 确定支持直接提醒；其余原始支持要达到固定强阈值0.4071309640537889。
- 仅上一相邻0.2秒采样的真实强证据可以保持一帧。保持不能刷新保持状态。
- UNKNOWN可以与提醒并存；未提醒不代表通道畅通。
- 原有评估数据的顶部统计始终对应当前数据集的完整Core布局，不随场景筛选改变。Boundary另行报告。
- 新增动态集合标为“机制演示 · 未标注”，没有评估真值，不显示 TP/FP/TN/FN、准确率或误报统计，也不进入“全量结果”。实际提醒与UNKNOWN仍原样展示。

## City Sample 高清场景

已加入六处位置、八段完整片段，每段24个采样，共192帧；核查记录见 [City Sample 交付说明](CITY_SHOWCASE_DELIVERY_20260920.md)。画面右上“1080p 原图”可打开完整分辨率图片。

| 原生位置 | 片段 |
| --- | --- |
| Big City · 石铺广场 | 钟柱与长椅接近后退开；侧向经过 |
| Big City · 林荫街角 | 广告灯箱接近后退开；林荫路侧移 |
| Big City · 住宅街区 | 花池与楼梯旁横向经过 |
| Big City · 城市街角 | 接近后退开 |
| Big City · 另一街区 | 广告亭附近横向经过 |
| Small City · 原生路桩 | 接近后退开 |

展示画面采用原生材质的1920×1080 beauty渲染。用于传感器代理的RGB与原生轴向深度仍为640×360；三种输出使用同一相机姿态、同一100°水平视场。提高展示清晰度不会把传感器输入变成1080p，也没有更换告警算法。

相机按预定姿态逐个设置、等待场景稳定后采样。页面每0.2秒一个时间标签，24帧覆盖0.0–4.6秒；它是分步姿态回放，不是引擎实时运动记录、24fps视频或实测处理时延。片段之间独立重置历史，不生成中间观测。

这些新增场景没有障碍事件评估真值，只展示实际观测驱动的冻结策略响应；不能把提醒称为命中、把未提醒称为正确拒绝，也不并入下方原有成绩。

## 数据与范围

原评估证据完整包含三组数据，每组36个布局、432帧，总计108个布局、1296帧；每组的Core288帧与Boundary144帧都保留。

| 数据 | 候选 Core TP/FP/FN | 用途 |
| --- | --- | --- |
| 新布局验证 | 74/10/0 | 冻结候选的一次前瞻受控验证 |
| 旧迁移回放 | 76/9/2 | 已消费数据；保留两处0.2秒HEAD首报延迟 |
| 早期开发回放 | 72/11/0 | 已消费数据；机制开发与上下文对照 |

额外动态场景由 `extra-data.js` 单独载入；无额外场景时该文件值为 `null`，画廊展示原有六类障碍。新增演示不改变上述1296帧分母或冻结研究结论。

RGB只用于展示；当前告警仅使用64区ToF几何与时间保持。
新布局验证的Boundary仅检出4/12事件，因此该候选限于声明范围内的主体演示，不能替代完整严格任务的Calibration。
这是受控仿真回放，不是实时设备演示，也不证明真实硬件、自然场景、人的反应余量或退出后的告警拖尾。

## 可选本地服务器

本页面通过本地脚本载入完整数据，没有fetch/CDN，正常情况下可直接打开。
若浏览器或企业策略限制本地文件，可在安装Python的电脑运行：

```text
python serve_demo.py --browser
```

服务器仅监听本机127.0.0.1，默认选择空闲端口。按Ctrl+C关闭。
Python仅用于这个可选预览方式，一键离线演示不依赖Python。

## 工程复现

源码位于 `research/active/dtr-r0/nearfield/core_alert_demo/`。
`policy.py` 提供统一 `CoreAlertPolicy.step()` / `reset()`；API只接受观测与时间线，不接受真值、BODY/HEAD或布局类别。
`build_data.py` 从原始64区观测重新执行冻结策略并核对封存输出，然后才加入评估标签。
`build_site.py` 装配页面。City Sample 的采集入口、分辨率与来源收据另见 [交付说明](CITY_SHOWCASE_DELIVERY_20260920.md)。构建收据位于上一级目录，记录数据来源、哈希与完整逐帧一致性。

浏览器只播放已经计算并核对过的因果输出。它不会从真值、显示颜色或四舍五入后的分数重新推断报警。
