## Official source and adaptation contract

Official [DEPTHOR repository](https://github.com/ShadowBbBb/Depthor), commit
`955adb306954be683f9cc1deb5f455b5c82ce19c`, and
[paper](https://arxiv.org/html/2504.01596v2) were checked via Exa; local source
was inspected directly. The official Small checkpoint is the README's
[Depthor-ZJU-Small](https://drive.google.com/file/d/1P5I54TZctkilvRMTAzMJHzZs9OdN1fBp/view).
No paper depth metric is claimed as BlindAssist alert performance.

Before this TRAIN mechanism protocol, one TRAIN frame was used only for strict
loading and equivalent CPU/GPU timing, without evaluator access or geometry
scoring. CPU/GPU max output difference.001378m, mean.000318m; measured medians
.83122s CPU versus.037423s CUDA. The subsequent48-frame prediction run uses CUDA.

Use `src.models.depthor_s.Depthor(n_bins=256,min_val=.001,max_val=10)`.
RGB is full640x360 resized to640x480, RGBfloat[0,1]; normalization occurs once
inside the official model. Output is the final CSPN result, clipped as official
evaluation to[.001,10]m, resampled back to360x640. Camera-axis depth is distinct
from slant range. No ground-truth scale fitting or metric recalibration.

Sparse input contains one value per single SIM_VALID public return at its
projected zone center, with radial range converted to camera-axis depth using
that center ray. This is a disclosed regional-to-point modeling approximation,
not the actual hit location. Missing, MERGED/multiple, invalid and out-of-image
center values become missing model inputs; raw evidence remains available. A
partial zone whose center is visible is marked separately and cannot authorize
deletion of its outside-RGB support. Never clamp invisible returns to image edges.

The full527-key checkpoint contains239Depth-Anything keys. Instantiate its
embedded ViT-S without loading the author's hardcoded absolute path, then require
strict full checkpoint loading. Initialize only official normalization buffers
after loading; no missing learned parameters are silently accepted.

Official CSPN uses BpOps local convolution. This machine lacks that compiled
extension. Implement only its inference operation with PyTorch unfold, matching
BP-Net's row-major, per-pixel weights and zero-padded borders. Compare against a
literal scalar implementation for3/5/7kernels and CPU/CUDA network outputs.
This is an execution port, not a new CSPN architecture or retrained replacement;
native CUDA-extension binary equivalence is not claimed without running it.

The official CSPN code comments out direct sparse-measurement reinsertion, so
neither dense output nor low input residual is a support-retention guarantee.
Any later readout must account for all explained RGB-visible support, retain
unexplained/MERGED/outside-RGB evidence and frozen Radar, and show residual votes.

## Interpretation and stop

This is a runnable strong-pretrained-model comparison at the **TRAIN geometry
stage**, not an end-to-end dev result. It gained effective information on larger
objects, while failing narrow objects under this simulation/input adaptation.
The failure is not fixed by increasing MZ139 search or loosening its thresholds.
It also does not prove DEPTHOR fails on ZJU-L5 or on every simulated scene.
Synthetic appearance, object size, limited input coverage and the regional-center
approximation differ from the pretraining/evaluation domain; causal attribution
among them remains unresolved. No official ZJU-L5 reproduction was performed.

Under the user's order to establish effective spatial information before dev,
the predeclared mechanism check stops this frozen direct transfer here. The
original24TP/FP<=10/5events/.25s alert target is unchanged and **unevaluated** for
MZ140. Do not turn TRAIN pixel/column gains or low forward latency into an alert
claim. No dense-surface alarm readout or residual-support deletion rule was added.
