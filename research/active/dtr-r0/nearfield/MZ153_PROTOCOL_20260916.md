# MZ153: causal video depth as an observation component

EXPLORE Development, 2026-09-16. This changes the observation model, not the
failed MZ151/MZ152 cutoffs. MZ129 remains the alert baseline. MZ148 established
some benefit from background-compensated RGB, but still missed a boundary frame.
The question is whether a frozen video depth model recovers thin/partial obstacle
surfaces from temporal RGB plus public regional ToF better than the same model
given repeated current observations.

## Fixed comparison and inputs

- Official DVSR Tartan checkpoint, upstream tree
  `bc9cd22153e1183310342b0a2a14e11f93b1be62`; strict parameter loading. Keep its
  bidirectional internal architecture. Each invocation sees only an already
  observed episode prefix; emit its last output. This is a causal prefix adapter,
  not the paper's forward-only network. No training or checkpoint selection.
- Use all 192 original MZ136 TRAIN frames, 16 scene configurations, 32 episodes
  of six frames. MZ146, dev48 and original test are not accessed by this run.
  Evaluator records are decoded only after both prediction arms are sealed.
- Temporal arm: current and all earlier frames of the same episode (maximum6).
  Repeated-current arm: repeat the current RGB/ToF for the same sequence length.
  An episode's first frame is duplicated to length2 in both arms because flow
  requires two images. Duplicates add no information. Reset at episode/gap.
- Match each 8x8 angular ToF cell to a16x16 block of a128x128 RGB guidance image.
  Project each angular sample into the original calibrated RGB using tangent
  rays. This angular rectification is a necessary disclosed adapter, distinct
  from upstream's usual uniformly sampled pinhole images. Out-of-RGB guidance
  is zero, recorded as unavailable. Never stretch the full70degree RGB into45.
- Each zone contributes its strongest public SIM_VALID target, with slot index
  as deterministic tie-break. Convert its slant range at the zone center to
  camera-axis depth; this is a regional hypothesis, not exact pixel ownership.
  Merged/missing/invalid regions are zero input, not clear space. The fixed
  public4m sensor scale normalizes depth into0..1; clip noisy overflow and count
  it. Preserve all original packets, alternate targets and independent branches.
  No native geometry, histogram, pose translation or future normalization enters
  the model. Roughly80% empty zones are a known transfer-domain limitation.
  Upstream preprocessing selects a10/20/40m scale using dense reference sequence
  percentiles; our fixed4m observable scale is explicitly a transfer change.
- Dense outputs are camera-axis hypotheses. Retain raw outputs; nonpositive or
  nonfinite values and areas outside common RGB/ToF coverage remain UNKNOWN.
  Mapping back to original pixels requires every interpolation contributor with
  nonzero weight to have a finite positive raw output; invalid neighbors cannot
  be averaged into a valid depth.
  No dense output can veto native ToF/Radar, and no App alert changes in this test.

## Evidence and decision

Use the existing MZ140 evaluator-only visible native AABB rasterizer and fixed
0.12m agreement diagnostic. It is collision geometry, not a captured UE depth
image. Report full visible-target pixel/column recovery (including uncovered
pixels), conditional common-FOV recovery, silhouette-ring spurious surfaces,
local precision, per-family errors, and returned native-contributor agreement.
Unknown background is not scored as free space. Reuse the exact same reference
and crop for both arms. Contributor agreement is a diagnostic of dense depth,
not proof that a sample represents a complete obstacle.

Keep the component for a separate alert-integration check only if all four
families recover at least50% of target columns (a column needs at least half its
visible target pixels within0.12m), both rod and shallow-boundary coverage improve
by at least5 percentage points over repeated-current, and aggregate local
precision does not worsen. Also report results on first frames versus frames
with genuine temporal history. This gate supports only a TRAIN mechanism result.
Failure stops this exact pretrained transfer before fitting, dev, or capture.
An unavailable/broken runtime is NOT_EVALUABLE, not a method negative result.

## Execution and recovery

CUDA inference using the existing isolated research runtime; no shared package
downgrade. Source-compatible operation adapters must preserve weights/keys and
be checked on meaningful synthetic operator contrasts. Source, checkpoint,
protocol, input files and outputs are hashed. Replay a real already-sealed prefix
after intervening invocations to detect leaked runtime state. Save per-frame
prefix provenance, timings, peak allocation, unknown masks and input slot choices.
The upstream optional mirror-flow shortcut is disabled for both arms: otherwise
identical depth frames set a sticky mirror flag and produce `flows_forward=None`
that `hg_forward` unconditionally reshapes. Compute both original SPyNet flow
directions; preserve all backward/forward feature-propagation branches. This is
a disclosed execution repair, not a forward-only network or a learned change.
No paid/remote allocation. Budget: one192-frame two-arm inference/evaluation,
1200seconds compute cap after model load. Mechanical failures may be corrected
with unchanged method, retained failed output and an explicit recovery receipt.
Release the process-local model when complete. Register the actual terminal via
supported tools; preserve the existing ledger303 failure if still present.
