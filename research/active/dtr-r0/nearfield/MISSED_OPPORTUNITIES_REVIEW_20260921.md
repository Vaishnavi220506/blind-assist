# 遗漏机会复盘：哪些价值被低估，哪些方向仍值得想

2026-09-21。只读证据复盘与候选建议；没有训练、采集、重算预测或开启 protected test。
核验基点为 `831abba1`。重点是当前 camera-forward RGB + 8x8 ToF，以及相关旧空间、
时序分支；这不是所有历史实验、L10、DTR/CARLA 的穷尽审计。

## 结论

找到了明确的局部收益、容易过度解释的失败，以及一个值得优先辨别的新问题。
但没有找到“某条已证实有效的完整方法，仅因规则而被彻底扼杀”的证据。
不能从存在停止条款直接推导其造成了机会损失。很多看似遗漏的方向已被后续试验覆盖。

最需要纠正的是把“未通过某个整体职责”压缩成“没有用”。历史门槛和失败保持原样；
本复盘保留这些方法的局部价值，不追认旧确认通过，也不为旧配方安排重试。

## 1. 已有价值：替换失败，不等于不能补充

[Spatial B](SPATIAL_BCE_RESULTS_20260920.md) 无法同时满足 Core 保留和误报预算，
关闭的是全量替换职责。随后已有的 [B 补充分支迁移](SPATIAL_COMPLEMENT_TRANSFER_RESULTS_20260921.md)
在新 16 布局上把 Boundary 当前 TP/FP/FN 从 `10/1/163` 提到 `128/10/45`，
事件检出 `4/16 -> 15/16`；Core 当前 FP 同时 `17 -> 36`。这证明有可用分类信号，
也证明它不是无代价告警升级。该机会已经被识别和验证，不能再当成未做过的新点子。

[R 的走廊相对表示](CORRIDOR_RELATIVE_RESULTS_20260921.md) 在消费过的 1152 帧上，
Boundary 带保持输出 `14/5/159 -> 78/6/95`，事件 `4/16 -> 11/16`；Core 带保持
`173/33/0 -> 173/38/0`。新增误报与段数均在原预算内，但 Boundary recall 45.09%
未达到 50% 要求，四组 HEAD 横杆为 `0/43`，已检事件首报延迟最多 1.8 秒。
其精度/召回/FPR 必须并报：Boundary precision 92.86%、recall 45.09%、FPR 2.84%。
它值得作为低成本局部机制保留，不能称为覆盖完整的方案；原非晋级结论不变。

更早的 [MZ146](MZ146_RESULTS_20260916.md) 在新 288 帧上由 `130/86/14` 到 `143/57/1`，
事件 `29/30 -> 30/30`，误报段 `28 -> 21`，但 rod FP `25 -> 29` 使联合条件失败。
后来的 [A baseline](corridor_fusion_v1/BALANCED_BASELINE_20260917.md) 实际继承了 MZ145
HGB 分数，因此不能说整个方法被丢弃。[MZ158](MZ158_RESULTS_20260916.md) 又出现局部
HEAD 误报退化，也说明不能只挑总量收益，抹掉细分类别的真实代价。

**复盘判断：确有容易被失败标签遮蔽的价值，但部分已经被后续工作找回。**

## 2. 当前最有价值的空白：到底学了几何，还是外观相关性？

[固定 B 扩充数据实验](DATA_COVERAGE_RESULTS_20260921.md) 保持网络和训练配方不变。
在新 1152 帧上，N 相比同选择规则的 B_control，Core 带保持 FP `66 -> 34`，
TP `172 -> 175`，但 Boundary 总 TP/FP/FN 都是 `106/19/70`。总量相等隐藏了交换：

| Boundary 家族，带保持 | B_control TP/FP/FN | N TP/FP/FN |
| --- | ---: | ---: |
| HEAD 横杆 | 12/1/34 | 43/7/3 |
| HEAD 悬挂平面 | 20/5/20 | 30/7/10 |
| BODY 突出平面 | 38/9/6 | 9/3/35 |
| BODY 悬空实体 | 36/4/10 | 24/2/22 |

N 没有整体升级：Boundary 额外误报和段数超预算，BODY 平面还丢掉两个原检出事件。
但同一模型家族的横杆召回可从 26.09% 到 93.48%，同时 FP 1 到 7，足以反对
“这种表示根本看不到横杆”的简单解释；它不是固定低误报下的可分性证明。

真正未隔离的是原因：本轮同时改变尺寸/高度覆盖及材质分配，不是同一几何逐外观
重渲染，也没有引入新拓扑。协议和 [源生成器](data_coverage_spec.py) 明确写出这一点。
旧 [MZ46](MZ46_SCAFFOLD_CONTEXT_RESULTS_20260911.md) 已提示环境依赖，但它移除了
支撑几何，连阴影和 ToF packet 也变了；它不能回答当前 B/N 的纯外观干预问题。

**首推的候选检查：给同一个障碍“换衣服”，几何和 ToF 完全不动。**

- 可用少量预先选定的训练/开发布局，例如 2 个 BODY、2 个 HEAD；保留完整短片和
  INSIDE/BOUNDARY/OUTSIDE 关系，不按模型表现挑最好看的帧，不触碰 protected test。
- 每个布局保留原场景，另做只改目标材质、只改背景纹理的两个条件；相机、所有几何、
  真值、光照设置、时间和 ToF 噪声身份固定。先确认深度与公开 ToF 逐值相同。
- 只调用冻结 B/N；不拟合、不重选阈值。报告逐帧分数/决策变化和完整事件误报、
  漏报、首报，分别比较目标外观与背景外观干预。差异不足时如实保留不确定性。
- 若相同几何仅换外观就导致系统性决策变化，才支持考虑“让外观与几何解耦”的
  数据/监督机制；若大体稳定，就降低这条解释的优先级。两者都不自动启动训练。

这是针对当前 B/N 的机制问题，不是声称反事实方法从未被研究。少量布局只能证实
局部敏感性，不能解释所有泛化失败。本节是建议，不是已冻结协议或已执行结果。

## 3. 大胆但仍属假说：允许模型预测未测部分

[整物体理想关联预检](IDEAL_ASSOCIATION_RESULTS_20260921.md) 是 NOT_EVALUABLE，
原因是所定义的 oracle 既要求完整物体范围，又不允许形状假设或未测深度推断。
稀疏返回与轮廓不能独自满足这种保证。这不是“RGB 不含信息”或“形状先验不准使用”。
该文件后续澄清已经明确允许实践模型预测未测区域，前提是标成预测，而非传感器事实。

一个可讨论的构想是“多种形状解释并存”：对同一轮廓和稀疏返回保留多个有限范围
解释，直接估计这些解释对走廊侵入判断的分歧，而非先恢复唯一的稠密深度。
预测应与原始 ToF 支持分开，几何不确定性保留 UNKNOWN；分类置信也不冒充测距。

这不是本轮首推，也不是获准重开稠密深度分支。旧 [MZ139](MZ139_SURFACE_FIT_20260915.md)
已测特定单 slab/搜索假设，存在低 residual 却错误排除真实支持；
[MZ142](MZ142_RESULTS_20260915.md) 的 fixed-BN 微调也确实严重损坏 BODY/HEAD。
未来若讨论此构想，先在明确歧义的少量合成场景中定义假设族，检查不同解释是否
能被可观测线索区分，且推断端不得读取真值形状。若不能区分，就报告歧义，不训练
一个貌似确定的答案。这里仅指出旧 oracle 没有排除的空间，不宣称新方法可行。

## 4. 时序和主动观察：不是没想过，剩余空白很窄

- [MZ155](MZ155_RESULTS_20260916.md) 固定扫描让杆类事件内曾获返回 `4/6 -> 6/6`，
  因果前缀可用帧 `24/36 -> 34/36`，但当前返回 `22/36 -> 19/36`。取得更多历史信息
  与可靠地利用它是两回事，不能记成“扫描没有任何信息”。
- [MZ179](corridor_fusion_v1/MZ179_RESULTS_20260918.md) 的小候选集历史可分，但当前
  Radar 和原分数历史也可分；没有证明新时序机制的增量，也没有证明所有时序无信息。
- [MZ182](corridor_fusion_v1/MZ182_RESULTS_20260918.md) 固定理想关联三相 dither
  `12TP/12FP -> 12TP/8FP`，未达到预设 50% FP 降幅。局部收益存在，原门槛仍失败。
- [MZ160](MZ160_RESULTS_20260916.md)、[NF-G6](STRUCTURE_INFORMATION_20260907.md)
  和 [轮廓视差后续](BA_CONTOUR_PARALLAX_20260919.md) 已覆盖多种平移/匹配想法；
  轮廓方案仍恢复 `0/4` 原漏例，P95 约 554.6ms 超过 200ms 预算，不值得改名再试。

较大胆的剩余构想是根据当前竞争解释，选择最能区分它们的下一观察，而不是固定扫描。
它只是在已审范围内未见执行的假说。当前 camera-forward 定义中转头会改变走廊查询，
未来任何此类比较须明确固定参考查询、相同测量/运动预算，避免把换问题算作补回证据。
这涉及额外观测和控制成本，优先级低于上面的固定几何外观检查。

## 5. 两条看似新机会，实际上已有工作

[多返回仿真](MULTIRETURN_PILOT_RESULTS_20260920.md) 已将 Core 当前 `73/8/5` 改为
`77/8/1`，但 Boundary `6/1/72 -> 18/8/60`；简单最近返回与双返回读出相同。
因此多返回的价值已有机制证据，复杂融合的额外价值没有，不能包装成尚未发现的路线。

[CNH 背景指纹](../../hardware-bringup/CNH_FINGERPRINT_20260921.md) 的整体 cosine
失败只关闭该评分配方；近远成分线索保留。复盘时已有未跟踪的
`research/active/hardware-bringup/CNH_COMPONENTS_20260921.md` 四步成分对照工作稿。
另有未跟踪的 `BRANCH_DISAGREEMENT_PROTOCOL_20260921.md` 正在准备 B/N 固定比特组合
诊断。它们没有被算作已完成结果，也不应在这里重复启动或列为本次原创建议。

## 取舍与边界

只选一个下一项时，建议优先审定“固定几何、改变外观”的小对照；其价值在于解释
已发生的 HEAD/BODY 收益交换，帮助选择数据还是表示方向，而不是继续换网络碰运气。
形状多假设与按歧义选视角保留为较大胆的待检验构想，不自动形成执行队列。

本复盘没有修改 baseline、阈值、历史负控、继承角色、共享账本或并行任务文件。
已提交报告为主要依据；未跟踪的 tail/pixel/oracle 原始报告不提升为已提交权威，
只采用 [已提交分层重审](EXISTING_RESULTS_STRATIFIED_REVIEW_20260920.md) 中已记录的范围。
没有证据证明规则是上述现象的唯一或主要原因；模型能力、数据、任务职责和传感器
信息都可能贡献。改规则能改善探索方式，不能预先保证新点子有效。
