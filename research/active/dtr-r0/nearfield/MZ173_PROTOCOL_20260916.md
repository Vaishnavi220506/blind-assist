## Metric scale and public evidence

DA3-Small depth is relative camera-axis depth, with one positive scale ambiguity,
unlike MZ157's two-parameter inverse-depth affine model. For every usable public
region, compute the arithmetic mean of predicted depth times the public pixel
ray norm over all integer pixels inside its complete angular footprint. Divide
the returned slant distance by that mean. The shared sequence scale is the
median of these per-frame/zone ratios; one eligible anchor identifies the one
scalar, with no residual/scale threshold or fitted offset. Save counts, scale,
ratio MAD and residuals so sparse calibration is visible.

An anchor needs a received packet, complete RGB footprint, exactly one positive
finite SIM_VALID return and no SIM_MERGED slot. Other returns/regions are excluded
only from dense calibration, never removed from raw sensor evidence. Missing
anchors give an all-UNKNOWN dense map. Invalid predicted pixels stay UNKNOWN.
The uniform region mean is a disclosed proxy for the simulator's weighted return
cluster, not true return ownership or a certified surface. Multi-return, merged,
outside-RGB ToF and Radar remain unchanged independent evidence.
Usable return metadata also requires finite nonnegative sigma and signal proxy;
every predicted pixel used for an anchor must be finite and positive.

Temporal scale uses unique actual prefix rows and their jointly estimated maps.
Control uses only its last current-frame prediction and current anchors, never
counts duplicate images as extra measurements. Thus this is the complete
causal geometry-plus-scale intervention; any gain is not attributed solely to
cross-image attention. Preserve all relative maps and current metric maps.
