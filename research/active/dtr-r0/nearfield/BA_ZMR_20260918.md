## Frozen comparison

Reuse the same 160 ZJU-L5 frames and sealed raw/UniDepthV2/DEPTHOR maps.
Threshold is 2m. All clipped official projected rectangles are processed before
reference-based mixed-zone scoring. Each rectangle's DEPTHOR near count k is
unchanged in rank and connected arms; no new depth value or ToF range is fitted.
Overlapping rectangles abort the run; saved audits also check union mass.

- DEPTHOR: original placement.
- MDE rank: existing UniDepthV2 depths sorted ascending, stable raster ties.
- Connected: minimum-depth seed, 4-connected greedy minimax frontier using depth
  percentile rank plus .25 times RGB adjacent mean absolute difference/255.
  Fixed queue priority, no tuning. There is no cached confidence output, so the
  seed is not described as high-confidence. One seed can be inappropriate for
  multiple objects; failure of this rule does not reject all surface grouping.
- GT-mass + MDE rank: reference near count and reference-valid selection mask.
  This is doubly privileged (mass and valid support), not deployable or a
  mathematical ceiling for arbitrary placement.

Metrics reuse reference-valid mixed-zone/raw-known pixels from the original
probe, and valid-reference jump boundary bands5/10px plus complements. Exact
full-zone mass can still move pixels into/out of invalid reference areas, so
evaluated mass is reported separately. Pixel precision/recall changes are not
causal evidence about measurement ownership or independent samples.

Model outputs, inputs and source protocol hashes are checked before use.
