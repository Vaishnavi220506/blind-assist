# MZ178-A: head/body decoupled current-frame support readout

Consumed MZ177 controlled Development, 24 sequences/1920 frames. No network,
training, source recapture, threshold tuning, scalar smoothing or new classifier.
Initial locomotion heading is frozen at zero per episode; head yaw is causal
public IMU integration. This assumption is specific to the source and is not
a hardware body-heading estimator.

Code inspection BEFORE new predictions finds MZ143 already rotates ToF centers,
interval supports, RGB plane hypotheses and Radar positions by public yaw.
Therefore the hypothesis that A* entirely lacks rotation canonicalization is
false. MZ178 tests an explicit geometric corridor readout of existing supports,
not a second rotation or a claim of newly introduced coordinates.

Compare saved A*, raw HGB and fixed hysteresis with two current-frame additions:

- head-frame control: A* OR any public support intersecting corridor, yaw=0;
- body-frame candidate: exactly the same union/readout with integrated yaw.

Use the inherited finite-zone slant enclosure: SIM_VALID range +/-3 sigma;
SIM_MERGED retains its inherited full0.02–4m uncertainty, never narrowed to a
point. Public packet/status/finite range/sigma/strength required. ToF extent
is shifted by known camera extrinsics; pitch is retained. Radar uses inherited
horizontal range/angle+yaw and no invented height measurement. Both sensor
branches survive independently of RGB/FOV. The fixed corridor is x[0.2,3.6],
y[-0.3,0.3],z[0.4,2.05]. An interval intersection means possible occupancy,
not confirmed target identity. No intersection or invalid IMU is UNKNOWN, not
clear space; invalid IMU adds no new alert and the original A* remains intact.

Save predictions and contributor IDs from public raw only before evaluator
access. Offline link contributors to native returned lineage to distinguish
target-supported recovery from coincidental alerting by another return.

Frozen A-to-B gate, declared before new output: recover at least64/106 baseline
head-turn target-supported FN (>=60% rounded up); total FP no more than61
(baseline59+2); side-pass duration no more than1.4s (baseline1.2+0.2);
head-turn transitions no greater than93; preserve all baseline warnings and
contact events. To attribute benefit to rotation rather than union readout,
body-frame must recover at least11 more of the106 than same-rule head-frame
control. Report contributor-attributed recovery as well; at least64 recovered
frames must actually have a target-linked triggering ToF contributor.

If any gate fails, stop this fixed A, do not tune or launch B. If all pass,
only then freeze a separate short-memory test; movement compensation and
unknown translation must be addressed before retaining historical points.
MZ177 has no public translation estimator, so B cannot borrow evaluator pose.
All frame metrics are correlated Development diagnostics. No safety, hardware,
fresh confirmation or paper-level novelty claim. Literature supplied by user
is motivation, not inspected evidence in this experiment.
