# MZ160: dense conditional temporal disparity

EXPLORE consumed capability and additive-alert pilot, 2026-09-16. Fixed hardware:
one RGB640x360 + original8x8 two-return ToF + Radar + IMU. No new capture,
hardware, trained model, native pose input or threshold rescue of a prior recipe.

## Distinct hypothesis and limits

MZ119's sparse LK/LP method produced points in only4 moving-scene frames, with
wrong context depth and no3.6m alert benefit. Dense horizontal correspondence may
recover textured obstacle surfaces that sparse anchor/query selection omitted.
This changes the correspondence representation and calibration method. It does
not solve the regional-ToF-to-pixel ambiguity or guarantee static anchors.

Use all240 already-consumed MZ119 frames, retaining the132 static-lateral frames
and108 rotation/stationary/low-motion/moving-object frames in every denominator.
The source has forward drift as well as lateral motion and noisy yaw. Public
IMU derotation does not establish exact horizontal epipolar geometry; residual
yaw is not exactly a constant image displacement. Treat this as a conditional
approximation, with no motion-observability or certified-depth claim. MZ119's
old negative result and its scoped historical stop remain unchanged.

## Frozen computation

At current time, use past lags2 and3 (.5/.75s). Warp each past RGB by public
IMU relative rotation and intrinsics; preserve warped-valid masks. Match current
against derotated past using OpenCV SGBM_3WAY, signed disparity range[-48,48),
block3, P1=72, P2=288, uniqueness10, speckle50/range1. Require explicit reverse
disparity consistency<=1px and valid warp footprints. Settings follow the
[OpenCV StereoSGBM interface](https://docs.opencv.org/4.5.5/d2/d85/classcv_1_1StereoSGBM.html);
this is a CPU implementation, GPU_BACKEND_UNAVAILABLE.

For each current single-SIM_VALID ToF zone, use one median matched disparity,
not one anchor per pixel. Reject merged, missing, partially clipped RGB zones,
and near-range-limit observations (range+3sigma>=4m). Convert regional slant
range to axial depth at the median matched pixel; this association is an
assumption. Fit d=a/Z+b using at least8 zones, inverse-depth span>=.03/m,
fixed-seed64 pair hypotheses, >=70% one-pixel inliers. Leave-one-zone coefficients
must agree in sign, exclude |a|<2 pixel*m and span at most50% of fitted a.
Residual90th percentile must be<=1px. The free b absorbs only approximate
residual image rotation. Pure-rotation and near-constant-depth controls can
expose spurious scale. A dense pixel count never increases independent anchors.

Use grid stride8 with horizontal Sobel magnitude>=4. Exclude the query's own
ToF zone from calibration. Combine leave-one-zone coefficient envelopes with
1px disparity error, intersect both lag depth estimates, and keep only positive
slant intervals within(.2,4]m and width<=1m. These are heuristic conditional
intervals, not calibrated uncertainty. Two-lag agreement can share wrong anchors.
No reference pixel identity is retained, so temporal actor correspondence cannot
be certified. Preserve all original sensor slots and no-alert UNKNOWN.

Compare unchanged current MZ129, using its frozen OpenCV5/source identity, with
MZ129 OR new possible-corridor point support at3.6m. Such additive readout cannot
reduce existing nuisance; this pilot tests credible new geometry and recall.
No old warning is suppressed. Seal public geometry and both predictions before
native evaluator parsing. Code/input snapshots, disparity maps, anchors,
calibration fits, point intervals and provenance remain saved.

## Evaluation, decisions and stop

Native obstacle AABBs plus frozen floor/background define analytic first-ray
hits. Source camera pose is a commanded reference, not independent native camera
readback; no rendered-depth or pixel-segmentation truth is claimed. All accepted
points enter containment denominator, including missing-reference cases.

Component conditions: correctly contained <=4m native-actor points in at least4
static-lateral episodes; at least10 correctly contained near_rod points across
at least4 static-lateral rod frames; >=90% accepted-point first-hit containment;
zero wrongly ranged CONTEXT points; zero finite near points in rotation-only,
stationary and low-translation controls. Correctly reconstructed near floor is
not a false-near context error. Report moving-object results separately.

Alert conditions: at least1 added true frame, no lost true frame/event or delay,
zero new false frames or family FP increases, and no originally native-supported
warning lost. Report ordinary/pressure (or pressure absent), every family,
precision/recall, events/delays, false segments/bin time, UNKNOWN, native sampled
retention and exact changed alerts together. Radar lineage is NOT_EVALUABLE.
Overall pass requires both sets; a component-only pass remains a scoped
challenger with no alert/default promotion. Any failure closes this fixed recipe
without threshold, scale-fit, matching, source or readout tuning.

One1200s public-inference allocation and one bounded native evaluation, no
capture/model fitting/parameter sweep. Mechanical fixes may preserve frozen
identities and be logged. Keep source/native boundaries, release owned processes,
and complete scoped delivery. The broader improvement goal remains active.
