# BA-RPCC-O0: rank-preserving cardinality oracle curve

**Close the RPCC training trigger.** With DEPTHOR ranking frozen, a single
global cardinality multiplier reaches only a small recall-preserving gain.
No cardinality head, mixture head, ZPA or SCDE training follows.

## Protocol

Reuse the same 160 sealed ZJU-L5 frames and 246 mixed zones from the oracle
decomposition. For each zone, keep DEPTHOR's continuous-depth ascending pixel
ranking fixed and select `ceil(c * k_GT)` pixels, clipped to valid support.
`k_GT` is privileged reference count. Scan c = .90,.95,1,1.025,1.05,1.075,
1.10,1.15,1.20,1.25,1.30. The output is a descriptive oracle curve, not a
trainable predictor or a threshold-selected deployment result.

The baseline recall constraint is 95.6887% (DEPTHOR 75.40% IoU). Select the
highest curve IoU with global recall at least that value; no interpolation or
posthoc c beyond the frozen grid. Also report per-zone unconstrained and
baseline-recall-preserving oracle ceilings, and secondary 1.5/3m curves.

The best grid point satisfying recall ≥95.6887% is **c=1.20**, IoU 78.27%,
precision 80.81%, recall 96.13%. This is only **+2.86 IoU points** over the
75.40% DEPTHOR baseline, below the predeclared +5-point training trigger.
The c=1.15 point misses the recall constraint. The high c=1.00 score is the
privileged GT-count arm already measured; it is not a learned cardinality result.

Per-zone unconstrained oracle reaches IoU 88.26% (246 zones); using each zone's
best multiplier with at least that zone's baseline recall reaches 90.05% on 190
eligible zones. These are reference-conditioned ceilings with incomplete zone
coverage, not evidence of a realizable head and not directly comparable to the
global curve.

Secondary 1.5m and 3m curves are retained in `results.json`; they do not alter
the primary decision. All predictions, input hashes and the source seal were
verified before scoring. No model inference, new data, threshold tuning, alert
integration or training occurred. CPU array operations only.

## Decision

Close RPCC as a training trigger: a single global conservative mass factor cannot
preserve the existing recall while delivering the required useful gain. This
does not prove a per-zone learned count is impossible; it says the available
zero-training ceiling is too small to justify starting it from this evidence.
Retain DEPTHOR as a descriptive geometry challenger and keep the prior negative
results for SCDE and ZPA. Any future revisit needs a materially different,
recall-constrained per-zone hypothesis and independent evaluation, not a sweep
of this same multiplier.
