# MZ110: ToF gate blocks six recoverable misses, removal is not sufficient

2026-09-13, consumed controlled Development diagnosis. The 288 unique frames
from MZ107--109 contain 176 positive and 112 negative frame opportunities.
No new capture, training, sensor simulation or production predictor change.

## Answer to the bounded question

Of nominal MZ108's **30 FN**, **10** have both a retained Radar return from a
true corridor obstacle and an existing RGB proposal with evaluator-supported
projected-box correspondence to that same obstacle. All ten pass the angular gate.

No nominal FN first fails proposal coverage, angular compatibility or original
reciprocal selection here. This does not establish those stages as solved on
natural imagery. All nine pole FN lack retained target Radar: the hypothesized
thin-pole ToF-gate failure is **not demonstrated by this source**. The six actual
ToF-blocked opportunities are one HEAD, two multitarget and three 1cm boundary
intrusion frames.

With correct projected-box identity supplied only for diagnosis, unchanged
nominal geometry could recover **6/30** nominal misses. Keeping or bypassing
the angle gate gives the same six. Unchanged interval readout could recover
4/30, including one different miss already restored by MZ109. These are
existential candidate-set recovery ceilings, not an achievable system score.
Native depth, true yaw and true boxes never replace measured range, integrated
IMU yaw or existing RGB proposals in the geometry readout.

Relative to the three-sensor baseline's 34 FN, 14 have paired evidence and 11
have positive nominal diagnostic geometry; some are already nominal TP.
The interval arm also has 34 FN, but its miss set differs. Five nominal-only
TP and one interval-only TP are explicitly listed in the result. Do not add
these overlapping denominators or ceilings together.

## Removing only the ToF gate

The observable counterfactual retains angular compatibility, both reciprocal
uniqueness conditions, measured inputs, nominal geometry and independent fallback.

Against nominal: four TP gained, zero TP lost; four old FP removed but five new
FP added. UNKNOWN totals are 113/110/115/105 respectively; UNKNOWN is not CLEAR.
Recovered frames are one HEAD and three boundary frames. Both multitarget
opportunities still abstain because the enlarged candidate set is ambiguous.
No pole FN is recovered. Opening the branch does not solve competing explanations.

All five newly added FP are real off-corridor boundary objects with supported
projected-box identity: the error is geometry, not ghost identity mismatch.
Conversely, one removed MZ107 FP comes from a **persistent ghost incorrectly
associated to a visible object**. That apparent improvement is not valid ghost
discrimination evidence. The remaining three removed FP are MZ108 boundary
frames. Aggregate FP conceals both the association error and localization errors.

## Decision

Retain the diagnostic decomposition as a component and preserve both existing
comparators. **Do not promote simple ToF-gate removal.** Association has limited
headroom on this consumed source, while missing target range and uncertain
geometry account for most residual misses and geometry adds irrelevant alerts.

A separately scoped successor should allow RGB+Radar candidates without ToF,
retain competing candidates and independent support, and address extent/readout
alongside association. Do not tune the consumed boundary frames or corridor
margins to erase the tradeoff. The proposed spatial evidence map remains a
design direction; see [mainline responsibilities](FOUR_SENSOR_MAINLINE.md).
This bounded diagnostic stops here without starting the successor.
