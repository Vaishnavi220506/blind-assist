# MZ162: return-conditioned visible face correspondence

EXPLORE, consumed original TRAIN only, 2026-09-16.

## Question and distinct mechanism

Can a selected regional ToF return identify and complete its linked visible
surface beyond the original zone, with useful metric geometry? MZ134 tested
weak algebraic attribution, MZ139 a finite slab, MZ140-142 unconditional depth,
and MZ161 direct corridor labels. None supplies a working learned per-return
visible-face relation. MZ138's sampled ownership splitting alone gave no gain;
extent outside sampled rays is the required opportunity.

This is an application of established association ideas, not a first claim:
[RC-PDA](https://openaccess.thecvf.com/content/CVPR2021/html/Long_Radar-Camera_Pixel_Depth_Association_for_Depth_Completion_CVPR_2021_paper.html)
learns radar-to-pixel association before depth completion. Its automotive
Radar setting differs from this hypothetical regional ToF simulation; no
published performance transfers to this experiment.

## Authority and first feasibility check

Use all192 original TRAIN frames in the authenticated MZ136 capture; no
original dev/test decoding, capture or hardware change. Independently audit
returned contributor lineage against saved native actor+face geometry. A
return can link several faces. SIM_VALID does not prove one owner; SIM_MERGED
does not prove several. Unknown owners or unresolved faces stay typed UNKNOWN.
Membership labels cover the union of known linked **visible first-hit faces**,
not all faces of an actor or hidden/occluded surface completion. A partially
unresolved query cannot make unmatched pixels negative by assumption.

Metric labels come from analytic first hits of saved native AABBs under
source-commanded camera pose, not rendered segmentation or independent camera
readback. Per-pixel slant is measured from the declared sensor origin. Each
visible pixel has one depth even if its queried return mixes surfaces. Relative
range offsets are diagnostics, never one scalar correction for a mixed return.

Before fitting, quantify whole-visible-face oracle coverage beyond each zone,
all target columns including unanchored frames, same-zone different-return
opportunities, and mixed/unknown/outside-RGB support. Target shape0 may identify
diagnostic denominators only; all named faces enter supervision. If the oracle
cannot recover at least50% of target-risk half-columns in every family, stop
this visible-return mechanism before fitting. An empty family denominator is
NOT_EVALUABLE. This scope test does not prove sensor impossibility.

Only after the feasibility check passes: scene0-2 FIT144 and scene3 HELD48.
The all-TRAIN feasibility audit has already accessed scene3 structure; HELD is
held out from fitting, not untouched design validation. This is consumed

native-detail/coarse-context encoder with GroupNorm, public zone geometry and
query-pixel head. The candidate receives selected-return attributes. The
control zeros those attributes but keeps the same shared image inputs and zone
coordinates; neither receives a slot index or evaluator identity. Thus two
returns in one zone remain identical queries for the control. Both output
membership and **log metric slant**, so the control never receives conflicting
relative-depth targets for one physical pixel. No frame BCE or hard maximum.
