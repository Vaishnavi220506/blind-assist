## Decision before model fitting

The exact-public interface is eligible only if it retains every native true
frame, loses no baseline true frame, introduces no false frame relative to
native, and retains baseline events/onsets. Both quantized readouts must retain
every exact-public true frame, add no false frame, retain events/onsets, and
achieve>=90%known-pixel precision and recall in each of the four families versus
the native first-hit mask. Undefined rates do not pass. These strict oracle
checks ask whether the representation itself already loses the distinction
that a trained decoder would need; they are not a hardware safety guarantee.

Report whole-frame TP/FP/FN/TN, precision/recall, UNKNOWN, families, ordinary/
boundary strata, original in/out pairs, events/onset, false segments; also
known-pixel confusion, half-column retention, native/public pixel changes,
overflow and query range coverage. Reuse native contributor accounting on saved
FIT references and disclose supported nonalerts. No per-return Radar lineage
is invented. Pose/quantization errors remain separate; do not correct them with
native pose or change bins after outcomes.

If these checks pass, the grid is eligible for a separately specified single
query-invariant learned distribution and matched probability-mass/point readout
comparison. It would isolate distribution collapse, not geometry supervision
versus direct risk learning or calibrated uncertainty. No training is included
in this diagnostic. If a check fails, stop this fixed grid/interface and report
which geometry prevents admission; no bin, phase, tolerance or cutoff sweep.
The broad goal remains active for distinct representations or observations.

## Related representation evidence

[Yang, Hu and Ramanan](https://arxiv.org/abs/1912.06268) formulate discrete depth
distributions that can retain multiple modes. The [MDA preprint](https://arxiv.org/html/2606.02552v1)
uses continuous mixtures and selects a depth hypothesis rather than averaging
foreground/background alternatives. These motivate a representation comparison;
neither establishes BlindAssist benefit. This fixed uniform-grid diagnostic is
our own feasibility test, not a reproduction of either method or their results.
