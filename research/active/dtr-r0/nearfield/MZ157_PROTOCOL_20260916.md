# MZ157: frozen relative RGB geometry with public regional range calibration

EXPLORE, consumed TRAIN capability experiment, 2026-09-16. Keep MZ129 and the
scoped MZ145/MZ148/MZ156 gains. Prior full DEPTHOR and DVSR failures remain closed.

Question: can a standalone frozen relative-depth prior supply thin geometry
that the prior complete learned fusion pipelines lost, when metric scale is
estimated directly from public regional ToF returns? Global calibration cannot
recover an object or depth ordering absent from the RGB prior. This is a direct
geometry capability test before investing in another learned alert readout.

Extract exactly 239 `depth_anything.` keys from the original authenticated
DEPTHOR-ZJU-Small checkpoint. Strict-load DA2 Small; use its original ImageNet
normalization and aspect-preserving 518/multiple14 preprocessing. Forward returns
a tuple: use only relative inverse depth, resized to original 640x360 before any
reciprocal. No fine-tuning, model download or old full-fusion inference. Compared
with MZ140 this changes both inference resolution and removal of learned fusion;
do not attribute that historical comparison to a single cause.

On exactly the original MZ136 TRAIN192 IDs, compare two mappings of the same RGB
prior: regional median control and regional two-mode calibration. Normalize each
relative map by its finite min/span, then fit positive affine camera inverse
depth `a*d+b`, with a in[0,100], b in[.05,100]. Slant range at a pixel is
`ray_norm/(a*d+b)`. Fit arithmetic mean slant range of32 deterministic within-mode
samples; it is a uniform pixel proxy, not the simulator's reflectance-weighted
native-ray mean. This mismatch and all inferred mode memberships stay explicit.

The candidate uses deterministic 2-means on relative depth within each complete
public zone (8 updates). Distinct valid returned slots use distinct noncollapsed
modes, evaluating both permutations. One return can choose either mode. Median
control uses the regional median prior and the same ray-norm sampling. Merged,
missing and partly outside-RGB zones are excluded only from dense calibration;
raw ToF/Radar evidence remains unchanged. Never treat a region center or inferred
mode as a verified hit identity.

Use constrained Huber least squares (.12m scale), max35 function evaluations per
solve, six fixed assignment/refit iterations and one final fit. Candidate has two
fixed starts (closest initial range and near-mode initial assignment); choose
only by public fit cost. No outcome-based search. Require at least six distinct
eligible zones, Jacobian singular ratio>=.001 and nonzero fitted slope; otherwise
the entire dense prediction is UNKNOWN. Rank/boundary/mode counts are saved.
Fit zones whose zone_id modulo4 is nonzero and report residual on held-out zones
as a diagnostic; final predictions refit all eligible zones. No held-out residual
cutoff is selected. All membership remains a hypothesis even at low residual.

Freeze model, code, protocol, original cohort IDs and input hashes before any
real inference. Seal all192 relative/metric predictions and calibration audits
before decoding only those native evaluator records. Never parse original dev,
test or MZ146 rows. Reuse the pure MZ140 native-AABB evaluator, preserving unknown
reference, visible columns, .12m diagnostic agreement, ring over-near error and
returned native contributors. Do not hide invalid dense predictions from target
pixel/column denominators; conditional MAE must show comparable-pixel coverage.

Retain the calibration component for further alert work only if regional modes
reach >=50% target-column recovery in every family, exceed median by>=5 percentage
points in both rod and shallow-boundary families, do not reduce BODY/HEAD column
coverage, do not reduce local surface precision, and do not increase referenced
ring closer-than-target error rates in any family. Report all counts even if the
joint condition fails. This is geometry, not an alert or independent-vote gate.
If it fails, stop this fixed mapping without extra iterations/resolution/model
or parameter tuning; record whether calibration validity or relative geometry
limits it. If it passes, retain only a consumed component and proceed to a
separately frozen alert integration; no automatic App/default promotion.

One192-frame run, 1200s computation cap. DA2 runs on CUDA; small SciPy calibration
and native bookkeeping use CPU (`TASK_NOT_GPU_SUITABLE`). Record real GPU/device,
timing, peak allocation and source bindings. Save mechanical failures without
changing the hypothesis, then release the process-local model in finally.

Literature inspected for mechanism and availability:
[Prior Depth Anything](https://github.com/SpatialVision/Prior-Depth-Anything)
separates relative geometry and metric priors;
[MTD](https://github.com/HenryMaxixi/MTD) uses segment-wise calibration but its
full fitting/noise-filtering release is incomplete;
[dToF-DMDC](https://github.com/KAIST-VCLAB/dToF-DMDC) reports code release pending.
This implementation reproduces none of those complete methods and makes no
claim that their point-prior contracts equal our regional dual-return contract.
