# 学习读出＋近场记忆：Development 快速诊断

**结论：历史信息有用，但不足以支持直接投入复杂可学习记忆。** BODY 宏 AP 从 0.730 提到 0.775（学习融合固定空间记忆），然而只平滑网络分数已达 0.780；同历史长度平滑再加空间记忆为 0.784，额外仅 +0.00418。小目标及时率收益很小，且实际假警有增加。本轮保留简单时序基线，不替换主线，不把 AP 提升写成产品报警改善。

## 主表

以下均为同一 v4 已消费 Development 的 64 个 audit 单位；0–15 共16个原 calib 单位拟合固定 C=1 的逻辑回归，16–31 共16个单位选报警阈值。各方法同为 **calib 10% 假警预算**。BODY 小目标近事件分母466，假警分母2832个空“序列×查询盒”；AP 是按单位宏平均。

| 方法 | HEAD / BODY AP | BODY 小目标及时 | BODY 小目标始终未报 | BODY 实际假警 |
|---|---|---|---|---|
| 冻结学习读出 NN | .838 / .730 | 143/466 = 30.7% | 268/466 = 57.5% | 251/2832 = 8.9% |
| NN＋空间记忆，学习融合权重 | .843 / .775 | 145/466 = 31.1% | 259/466 = 55.6% | 286/2832 = 10.1% |
| NN 最近5分数加权平滑 | .840 / .780 | 147/466 = 31.5% | 263/466 = 56.4% | 306/2832 = 10.8% |

平滑权重固定为距今每帧减半，不搜索参数；单个 NN 使用最多4帧，因此5个连续分数覆盖最多8个原始帧，与既有 S3 记忆的名义历史长度一致，但空间信息不同。平滑＋记忆相对平滑的 BODY AP 配对差值为 +.00418，单位 bootstrap 描述性95%区间 [.00248,.00596]；HEAD 为 −.00111。5%/20%预算也完整保留，收益并非各预算下一致的及时改善。NN＋S2 学习融合的 BODY AP 为 .73004，几乎没有额外排序收益；但不据此声称所有报警工作点完全相同。

## 诊断与排除

- **差距诊断**：同10% calib序列预算下，学习读出漏掉的可见小目标正帧中，条件信号参考 z4<2 占 HEAD 2154/2745（78.5%）、BODY 2933/3465（84.6%）。但 BODY z4≥5 时 NN 检出158/207，S2为175/207，不能宣布读出已饱和。条件理想参考采用逐帧名义5%假警，与序列预算不同，不能相减为可实现提升或解释为物理上限。[完整差距诊断](../../../../artifacts.local/work/cnh-learned-gap-20260928/REPORT.md)
- **直接取最大值不是好融合**：先前固定分位数融合用全部32个 calib 单位，BODY AP .730→.763，却使实际假警8.9%→12.5%、小目标及时30.7%→28.8%。此轮与主表校准子集不同，报警值不得跨表直接比较。原结果及 NN_RANK 离散化对照均保留。[固定融合结果](../../../../artifacts.local/work/cnh-learned-memory-20260928/result.json)
- **完整交付**：[同历史对照结果和模型系数](../../../../artifacts.local/work/cnh-learned-memory-20260928/equal-history-control/result.json)；[首轮学习融合](../../../../artifacts.local/work/cnh-learned-memory-20260928/linear-fusion/result.json)；[独立复核](../../../../artifacts.local/work/cnh-learned-memory-20260928/review.json)。冻结 NN/S2 宏 AP 与既有 v4 文件逐值相同；预测、标签、config、frame 对齐。4项聚焦测试通过，复核确认各校准预算达标、事件分母一致、无未来读取或跨序列记忆。推理使用 RTX 5060 Laptop GPU，96单位预测阶段约9.7秒；最终标量融合/评估CPU约4.8秒，无新数据合成、CNN重训或付费资源。

**下一步判断：优先保留简单时序对照，暂不扩大记忆网络。** 若继续研究，主要问题应是约束实际提醒负担后的事件及时性，以及停止/转身/障碍离开时的错误保持；本轮没有相应新场景，不能声称已解决。序贯部分只检查固定因果平滑，并未实现有似然校准的 SPRT 或 TTC 策略；硬件交替配置未实施。

**范围与局限**：本轮由用户“试试吧”授权，是结果驱动、已消费 v4 的探索；后续融合和平滑控制是在看到前一阶段后追加，不能视为独立确认。拟合、阈值、audit 三部分按单位分开，但 v4 历史上已被查看。学习的是既有空间记忆的融合权重，未学习记忆构建或遗忘；记忆可用指示在拟合集恒为1、权重为0。强信号小目标 BODY 只有207正帧，不作因果归因。所有数字只支持当前生成器内诊断；真机噪声未可靠标定，序列假警不等于每分钟提醒负担。没有修改 CURRENT 或任何历史正式结果。
