# MZ164: camera-aware metric monocular prior

EXPLORE consumed original TRAIN192, 2026-09-16.

Question: can a metric-trained RGB model supply useful obstacle evidence when
the fixed ToF has no target return? MZ157 already tested a frozen relative DA2
prior plus regional ToF calibration and recovered zero rod columns. MZ164 changes
the learned prior to official UniDepthV2 ViT-S, which predicts metric geometry
and accepts camera rays directly. No calibration fit, fine-tuning or ToF-centered
pixel-depth assumption is made. This is a new prior/interface comparison, not a
new invention or rescue of MZ157, MZ161 or MZ162.

Two fixed arms use the identical frozen model and preprocessing:
`known_camera` passes the public RGB intrinsics; `estimated_camera` supplies no
camera, using the model's camera estimate. Known intrinsics are the candidate;
do not select an arm after scoring. Both remain point-estimate hypotheses.

Native RGB360x640 is bilinearly resized to364x644, exact independent x/y ratios.
The adapter changes integer-centered project intrinsics into upstream's half-
pixel coordinates: fx*sx, fy*sy, (cx+0.5)*sx, (cy+0.5)*sy. resolution_level0
keeps this234416-pixel input within the model's200000..240000 pixel range, so
internal resize/padding is identity. Restore camera-forward z depth bilinearly
to360x640. This predeclared adapter avoids upstream shape-rounding/camera-scale
mismatch; it is not input or threshold tuning. The returned learned K remains
a learned estimate even when known camera rays are supplied. Confidence is a
within-image ranking, not calibrated metric uncertainty, and is not a gate.

## Seal, metrics and decisions

Seal both arms'192 metric maps and observable alert flags before this run parses
selected native evaluator records. Offline references use saved native AABB first
hits and source-commanded pose, not rendered depth or complete scene truth.
Use inherited0.12m surface agreement, half-column coverage,8pixel silhouette
ring errors, and returned native contributor checks. Report every family and
three evaluator-only current ToF strata: no target-containing returned slot of
any status, MERGED-only target evidence, and VALID-supported. Stratification is
never a predictor input and does not certify Radar absence or target-exclusive
returns. Missing reference areas remain UNKNOWN.

Report whole-frame TP/FP/FN, precision/recall, UNKNOWN, matched true retention,
events/timing, ordinary/pressure strata, paired decisions and native ToF retention.
Keep geometric accuracy separate from alert benefit. Retain an alert-addition
component only if the known-camera OR arm gains at least one true frame without
any new FP, lost existing true event/time or newly suppressed native contributor.
For the intended no-return mechanism, additionally require at least one such
gain in the no-target-return stratum with an8-connected patch of at least9
target-corridor pixels agreeing with reference axis depth within0.12m. Mere
overlap of predicted/reference corridor masks is reported but is insufficient.
Otherwise any gain is scoped to its measured mechanism.
The known/estimated comparison explains camera conditioning; it is not a search
over checkpoints. Report geometry even if no alert gain; stop this fixed model
and readout without threshold, resolution, checkpoint or fitting rescue.
