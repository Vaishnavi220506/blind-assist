# MZ113: causal optical correspondence under moving obstacle events

EXPLORE, 2026-09-13; part of the active multiple-method mainline optimization.
MZ111/112 improved static-source recall but not persistent ghost discrimination;
most temporal TP gains survived zero Doppler. The next useful question is whether
current pixel motion can preserve correct range correspondence through obstacle
motion while dropping old support when an object exits the corridor.

## Fixed methods and contrasts

Keep all MZ111 methods and their ToF/Radar/IMU/RGB inputs unchanged. Add one
current-RGB optical-flow persistence candidate, retaining original nominal
positives and independent ToF. Current unique RGB/Radar angular pairs (12deg)
seed range tracks; a current competing Radar return prevents gap rescue.
During a true measurement gap, track region features with pyramidal LK and
forward/backward agreement, transform the previous image box by median motion,
and require reciprocal IoU>=0.2 with a current pixel-derived proposal. Missing
image/texture, correspondence ambiguity, invalid IMU/time or age>0.5s resets.
RGB updates never refresh the range measurement's lifetime.

Frozen optical constants: at most40 Shi-Tomasi corners per prior region,
quality0.01/min-distance3px; LK21px window,3 pyramid levels,20 iterations;
forward/backward error<=1.5px and at least3 valid points. This supports a
correspondence hypothesis, not certified identity or dense geometric depth.
Use measured radial velocity when finite; otherwise explicitly mark velocity
UNKNOWN and hold the last measured range. No fabricated velocity or confidence
from repeated alerts. No true pose, object identity, native geometry or future
image/measurement enters either predictor.

Use an angular-correspondence ablation with identical missing-velocity handling
to isolate optical flow from that engineering difference. The new combined
primary is unchanged MZ111 filtered-plane support OR additions unique to the
flow branch (flow AND NOT nominal). Its angular ablation uses the same formula.
The original MZ111 combination remains the primary incumbent. Do not choose
parameters or switch the primary after outcomes.

## Measurements and decisions

Report all arms' TP/FP/FN/UNKNOWN, absolute HEAD/pole recall, retained incumbent
and nominal TP, and per-event first alert delay/missed events. Report false
support duration/segments and post-exit false support separately; scores must
not hide object exits in all-positive episodes. Discrete0.25s bins are simulation
timing, not measured user burden. Check past/current source identity and evidence
age for changed temporal supports; optical matching can still attach a ghost or
wrong object. No candidate classifies missing support as CLEAR.

A gain requires useful recall/timing retention and a nuisance benefit against
the incumbent on the affected strata; report any tradeoff instead of declaring
uniform improvement. Compare optical flow against the angular ablation, not just
an inferior old missing-velocity policy. A failure closes this fixed candidate;
keep diagnostics and continue the larger authorized goal with a new information
or representation hypothesis. Never retune the consumed source's thresholds.
