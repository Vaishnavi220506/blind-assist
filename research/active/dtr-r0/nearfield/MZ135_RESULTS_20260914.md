## Fixed hardware and actual experimental change

The [brief](MZ135_TEMPORAL_BRIEF_20260914.md) freezes the same 288 consumed MZ123
RGB + 8×8 ToF + Radar + IMU inputs, current frame plus four causal past frames,
and no training. All original RGB hashes match the MZ125 authenticated cache.
No source identity, commanded displacement, native geometry, future frame or
label enters prediction. Optical flow transports image-space footprints;
IMU rotation is used for motion-residual diagnostics, not metric translation.

The [implementation](mz135_temporal_dealias.py) tracks real pixels with
forward/backward LK. A current VALID return links to all range-compatible prior
VALID returns containing its shared image tracks. For each reference, translated
prior zones are combined by their bounding box; at least two past references
are required before intersecting these envelopes with the current saved ROI.
Flow transport uses a declared 2px pad and a broad 2m/s relative-range nuisance
allowance. The current ROI's outside-image part remains. Competing tracks are
retained in each reference union; missing associations and MERGED fall back.

Positive temporal associations have actual decision authority: narrowed return
support replaces the old support before the ToF readout. The old complete alert
is not OR-ed with the new complete alert. This ToF experiment retains MZ129's
independent Radar/raw/carry/guards and certain-coarse protection as controls;
the separate ToF-only result shows that Radar is not hiding a temporal gain.
`attribution_score` is the count of matched past references, not a probability.
The source of an untracked contributor inside an associated beam is a model
risk, not an automatic veto preventing the experiment.

This candidate addresses **VALID return attribution only**. All 266 MERGED
records keep their previous support and range bounds. Temporal MERGED demixing,
a joint Radar-motion risk model, and a trained cheap-sensor student remain
unimplemented; this result must not be presented as having tested them.

## Temporal information and failure evidence

192 frames have the full five-frame window; 24 each have one, two, three and
four frames at episode starts. There are 912 reference/current pair records,
50,068 shared-feature pair records and 1,449 cross-zone feature movements.
These are repeated track/pair observations, not independent surfaces. In 201
pairs the median IMU-compensated pixel residual exceeds 2px. This proves
observable image motion exists, not that it is camera translation.

Among 3,954 returned records, 853 receive conditional narrowing, 1,012 have
enough linked references without changing their envelope, 1,823 have
insufficient references, and 266 are unresolved MERGED. Seventeen individual
possible bits disappear across the whole panel. Other returns still sustain all
affected whole-frame alerts; the ToF-only null establishes this directly.

The evaluator audits all 27,753 native contributor samples. All were contained
by the saved input ROI; the candidate newly excludes 225, including 31 actual
corridor samples. No outside-RGB contributor is newly excluded. One concrete
affected return is zone44/slot0 of `mz123_substantial_body_pair2_in_03`.
Unchanged alert counts therefore do not establish correct spatial retention.

Of 18,025 proposed feature-linked return edges, 563 link **disjoint known actor
sets**. Unknown-environment edges, where one side lacks a known actor ID, are
counted separately and are zero here. `None` is never treated as a common actor.
Even a common actor would not prove that an image feature and a ToF component
come from the same local surface, or that its whole footprint shares the
tracked pixel's displacement. These violations explain why positive pixel
correspondence alone does not justify the tested surface transport.

The frozen falsifiers explicitly exhibit three boundaries:

- Repeating stationary support does not manufacture a finer envelope.
- Moving camera/static surface and fixed camera/coherently moving surface can
  have identical relative coordinates. This is a constructed kinematic ambiguity,
  not a claim that two fully rendered multisensor packets were matched.
- Exact roundtrip image correspondence can still associate a background feature
  with another ToF reflector in the same zone; conditional envelope intersection
  then removes a real untracked contributor. This is a model counterexample,
  not a calibrated frequency estimate.

MZ119 already observed moving-anchor corruption of inferred camera translation.
MZ135 avoids metric pose inference but finds a related ownership problem at the
pixel-to-return and whole-footprint transport steps. No static-scene guarantee,
flow pad adjustment, stricter association cutoff or post-score threshold rescue
is added to this consumed result.
