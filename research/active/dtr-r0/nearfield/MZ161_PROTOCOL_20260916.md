# MZ161: dense local corridor-task supervision

EXPLORE consumed TRAIN scene-heldout comparison, 2026-09-16.

Hypothesis: spatial task labels can reduce whole-scene shortcuts when a shared
high-resolution model learns which visible surface pixels lie in the walking
corridor. This differs from MZ120/122 cell pooling, MZ136 frame ranking,
MZ141/142 metric-depth loss, and MZ147/150 global HGB readout. Shared fusion and
dense supervision individually are not new. The architectural background is
[fully convolutional prediction](https://openaccess.thecvf.com/content_cvpr_2015/html/Long_Fully_Convolutional_Networks_2015_CVPR_paper.html);
no standard convolutional method is claimed as a new invention.

## Fixed comparison

Use only original TRAIN192 from MZ136: scene0-2 are FIT144, scene3 HELD48.
These are already-consumed simulation scenes, not fresh confirmation. No
original dev/test access, new capture, hardware change or pretrained model.
Native actor AABB first hits under SOURCE_COMMANDED_REFERENCE supply offline
FIT pixel labels; unsaved geometry is UNKNOWN. All saved actors participate.
Visible first-hit intrusion is distinct from full-volume frame hazard; measure
their mismatch and retain separate frame labels and sensor paths.

Both arms use identical seed161016, initialization, sample orders, optimizer
and 20 epochs (720 updates each), batch4, AdamW lr0.001, weight_decay0.0001.
No augmentation, early stopping, checkpoint choice, sweep or threshold tuning.
Control loss is frame BCE. Candidate adds one times class-balanced known-pixel
BCE: positive/negative class mass0.5 each when both exist, sole class mass1,
unknown mass0. Exact implementation is mz161_dense_task.py and dense_labels.

The 10,850-parameter model keeps 640x360 processing, 24 channels and dilations
1,2,4,8,16. RGB, both regional ToF slot maps, public ray/corridor entry/exit
geometry and validity feed the pixel branch. Inputs are cached as float16 and
converted to float32 for training; parameters, losses and outputs are float32.
Half-open raster regions avoid adjacent-zone overwrites. ToF range is a
regional observation, not known pixel depth. No IDs, family, source pose or
evaluator data enter the predictor.

All128 ToF and4 Radar slots have an independent shared token path, including
valid RGB-external returns. Frame logit is max of query-ray-eligible pixel
logits and usable token logits. Threshold is fixed zero; no-alert is UNKNOWN.
Raw pixel logits remain available for dense loss and diagnostics. Exact max
may starve a losing branch under frame-only loss, and ambiguous sensor logits
may prevent RGB from reducing nuisance. Record pixel/token maxima, winner and
separate decisions. Input retention alone does not establish native alert
retention. Coordinate-conditioned shared processing is not invariance to
shifting RGB alone.
