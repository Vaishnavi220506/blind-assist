# 历史机制继承批次：三个组件有收益，一个续报配方关闭

2026-09-22，用户授权“直接把这些试试”后完成的有界 EXPLORE。
历史复盘的八个继承点合并为四项可判定试验，各自先固定机制、对照与停止条件。
本轮完成的是这四项，未将所有历史算法重新训练或接入 App。

**最值得继续保留的是按查询组织局部几何和视觉证据的表示。** 它在相同公开
RGB+ToF 输入下，明显优于匹配的原始特征树模型。多返回和精细测距也有真实的
受控信息增益，但分别假设额外的返回通道和更细的量测能力。事件支持继承配方
消除了旧保持的额外误报，同时消掉全部补漏收益，按原判据关闭。

## 四项结果及代价

前三项复用同一已消费的 query-occupancy 来源，主评估分区均为 576 帧、
16 个基础布局、256 正帧、320 负帧、32 个正事件。各项没有合并为一个系统；
同一批帧的重复使用也没有增加独立样本量。表内三元组为 TP / FP / FN。

| 试验 | 固定对照 → 候选 | 收益与代价 | 继承决定 |
| --- | --- | --- | --- |
| [局部查询表示＋小型 HGB](INHERIT_SPATIAL_RESULTS_20260922.md) | A：193 / 6 / 63；A+RAW：200 / 12 / 56 → A+LOCAL：223 / 8 / 33 | 相比 RAW 多 23 TP、少 4 FP；相比 A 多 30 TP、2 FP、2 个误报段 | LOCAL 保留组件；原始特征配方为负对照。超过相对 A 的 +1 段预算，未晋升告警方案 |
| [多返回信息保留](INHERIT_MULTIRETURN_RESULTS_20260922.md) | 原返回＋原保持：225 / 26 / 31 → 最近导出返回＋相同保持：254 / 29 / 2 | 多 29 TP、3 FP、2 个误报段；入区首帧提示 17/32 → 31/32 | 保留额外观测信息组件；Core 无增成本判据未过。双返回复杂读出与最近返回完全相同 |
| [事件支持继承](INHERIT_EVENT_RESULTS_20260922.md) | 原保持：225 / 26 / 31 → 支持继承：193 / 6 / 63，恰与 A 当前帧相同 | 去掉保持新增的 20 FP，也去掉它新增的全部 32 TP；保留率 0% | 固定配方为负对照；不据此否定所有时间机制 |
| [更细量测＋共享偏差推断](INHERIT_PRECISION_RESULTS_20260922.md) | 180 个解析场景，名义正确明确判断 97 → 109；UNKNOWN 83 → 71 | 新增 12 个正确判断，无旧判断损失；两偏差条件分别新增 23、25 个；未观察到错误 IN/OUT | 保留假设精细量测的信息组件；不是当前硬件精度或近场告警成绩 |

局部表示的主候选是 A OR 模型，未移除 A 的任何告警。单用 LOCAL 虽有
207 TP / 4 FP / 49 FN，却只覆盖 31/32 事件，因此不在看到结果后改选它。
相比 RAW 的净增 23 TP 由新增 24、丢失 1 个组成，且一个事件首报晚 0.2 秒；
它并非逐例无损优于 RAW。12/16 布局改善，配对布局召回差的条件 bootstrap
95% 区间为 [5.86, 12.11] 个百分点，不能据此声称独立来源泛化。
多返回当前帧也有 193/6/63 → 211/7/45 的增益，18 个新 TP 均有实际触发
第二槽的原生走廊贡献者；不是只靠保持把帧数延长。

前三项的主候选都维持 32/32 事件，区别主要在覆盖、首帧提示与误报负担。
多返回保持还有一个释放时间右截断事件：已观察退出，但片段结束前未观察
后续静默。不能把已观察的 0.4 秒尾部称为完整释放时长。

精度项采用相同 13 视图、12 厘米路径、初始相机查询与共享误差范围，仅把
已保存的模拟原始距离导出为 1 毫米分档。名义边界正例仍只识别 5/30，远边界
20/20 UNKNOWN；它排除部分替代解释，没有解决边界可辨性。剩余 UNKNOWN
都有可回放的 IN/OUT 双见证。三个偏差条件不是三个独立场景集。

## 八个继承点如何落到本轮

| 历史机制 | 本轮实际检验范围 |
| --- | --- |
| 事件身份、新鲜度、首次触发与续报分开 | 只做同区原始支持、有效时限、非递归继承的固定候选；可观测同区不等于物体身份 |
| A、Raw/HGB 等简单强对照 | 保留当前双传感器 A；匹配 RAW/LOCAL 两次固定树模型拟合，没有移植旧四传感器分数 |
| 任务条件几何和查询表示 | 六个固定查询；比较原始区域特征和查询区间分组表示 |
| 时间三态、短历史、受控运动工具 | 检验支持续报及事件时间；真实 detector-track 七帧三态和 TCN 未跑，缺少实际检测轨迹，记为 NOT_EVALUABLE |
| L10 的局部证据与承载范围区分 | 继承到局部支持表示；没有重新跑完整导航控制器或证明像素归属 |
| 多返回/CNH 信息 | 复用冻结模拟返回生成律；第一槽逐帧一致。物理 CNH 采集仍暂停 |
| 主动观察、路径中的信息 | 精度项沿用原固定路径；没有新选路策略，也没有声称主动反馈更好 |
| 共享偏差、竞争几何、一致参考查询 | 原共享误差推断与初始参考查询不变，只检验更细观测能否转成判断 |

这组结果支持两个具体判断：相同输入的表示方式仍有改进空间；传感器导出
信息的粒度也会限制判断。但没有证据表明三个正组件拼起来收益可相加，
更没有形成一个已经通过整体告警代价检验的新系统。

  空间模型每臂拟合一次，精度执行 878 次固定 MILP，没有追加参数扫描。

  3,456 查询，多返回审计 576 帧、27 个完整分组及原生贡献者。

  包括协议/代码快照、来源哈希、公开预测、逐例得失、分层及时序指标、审计与运行收据。
  这是四类路径的缩写，不是一个实际目录。
- 所有任务计算退出，无持续 worker 或付费资源。原 A、UNKNOWN、已消费负结论、
  默认 App 和物理采集状态保留。本轮到此结束，不自动启动后继实验。

上述试验没有输出物体分割或像素深度，不能据其告警改善声称 IoU 或距离精度

受控 Development 和解析模型，不支持自然分布、实机或使用者受益结论。
