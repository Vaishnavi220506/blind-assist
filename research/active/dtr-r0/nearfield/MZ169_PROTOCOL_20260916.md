# MZ169: learn a combination of frozen corridor experts

EXPLORE, consumed Development, 2026-09-16. Written before new fitting or scoring.

## Question and separation

Can a learned combination reduce nuisance while retaining existing true alerts,
compared with both MZ129/MZ145 and a matched equal-weight combination? MZ158 found
useful current/temporal complementarity but failed HEAD nuisance; MZ148 and MZ159
lost specific true frames. Those fixed complete recipes remain closed. This is a
new learned readout, not a threshold repair of those results. MZ167/168's tested
range/pose interfaces are not extended here.

Four expert weights remain frozen after original MZ136 TRAIN192: MZ145 static,
MZ148 unregistered, MZ148 compensated, and MZ159 reflection. Repeat-control is
not a fifth independent expert. Meta-training is only consumed MZ146288, whose
labels none of these expert fits used. Original TRAIN OOF tables are not stacked
or described as nested cross-validation. Expert selection and all evaluation
panels have historical selection exposure: this is not fresh validation.

## Fixed implementation

- Ordered inputs: static, unregistered, compensated, reflection probabilities.
  Clip to [1e-6, 1-1e-6], then logit. No identity, family, native geometry or
  evaluator value enters the predictor.
- Candidate: StandardScaler fitted within each meta fold, then logistic regression,
  C=1, lbfgs, max_iter=1000, random_state=169016, ordinary L2, no class weighting.
  Fit four meta folds and one full model. No interaction, tuning or search.
- Meta folds: sort the 24 complete scene-group names and assign cyclically modulo4;
  both paired episodes and all their frames stay together. Six groups/72frames
  per fold. Freeze the mapping before fitting.
- Matched control: arithmetic mean of the same four logits, with no fitted weights.
  Its scores need not be probabilities. Both arms use the original causal rule:
  one above-high observation or two consecutive above-low observations, .25s
  cadence, episode/gap reset.
- Both low/high cutoffs use the same meta-training required mask: truth AND
  (saved MZ129 OR saved MZ145). Low is the minimum required OOF score; high is the
  minimum required score lacking a preceding above-low observation. Candidate
  calibration uses grouped meta OOF; control uses its unchanged scores. These
  calibrated meta summaries are training diagnostics, not unbiased validation.
- Save fold models, full model, all OOF scores and cutoff-support cases. Seal the
  model/cutoffs before any new dev prediction. Do not fit an expert again.
