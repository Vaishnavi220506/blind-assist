# MZ166: query-conditioned dense corridor supervision

EXPLORE, consumed original TRAIN192, 2026-09-16.

Question: does teaching the same image to answer different corridor positions
improve intrusion discrimination with frozen pretrained local context? MZ150's
seven-query global-feature learner failed; MZ165 established a matched benefit
from pretrained context but retained boundary errors. Seven queries are not new.
The distinct test is dense query supervision over that local representation.

reference receives zero loss. This is analytic reference, not rendered labels.
