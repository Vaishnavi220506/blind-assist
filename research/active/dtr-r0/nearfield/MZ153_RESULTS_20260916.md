# MZ153: pretrained causal video depth does not recover missing thin surfaces

EXPLORE Development, 2026-09-16. [Protocol](MZ153_PROTOCOL_20260916.md).
Decision: `STOP_FIXED_PRETRAINED_TEMPORAL_TRANSFER_KEEP_MZ129`.

**A frozen DVSR video model improves shallow-boundary column recovery from
84.19% to87.85%, but rod recovery falls36.88% to35.70%. Aggregate local surface
precision slightly falls86.115% to86.035%.** All three declared geometry
conditions fail. Stop this exact pretrained transfer before fitting, dev scoring
or capture. No alert gain was tested or established; MZ129 remains retained.

## What changed and what was actually measured

The official15,494,556-parameter DVSR Tartan model was loaded with all592
checkpoint keys, without missing/unexpected keys or training. Its original two
hourglasses and four backward/forward propagation passes remain. Each call
receives only an already observed episode prefix and returns its latest frame;
this is a causal wrapper around a bidirectional network, not the paper's
forward-only model. Compare against the identical model given repeated current
RGB/ToF for the same sequence length. First frames duplicate the current frame
for the two-frame flow interface, adding no information.

All192 original TRAIN frames,16 scene configurations and32 six-frame episodes
are evaluated. Each of the four families contributes48 frames. Both output arms
are sealed before decoding selected TRAIN native evaluator records. The native
reference is a first-hit raster of saved collision AABBs, not a UE depth image.
Coverage means a visible target column has at least half its pixels within the
fixed0.12m depth agreement band. Local precision counts agreeing target pixels
against target-like wrong depths in an8pixel referenced silhouette neighborhood;
it is not alert precision, free-space accuracy or whole-image surface accuracy.

## Input and coverage limits

The declared adapter matches angular8x8 ToF cells to128x128 RGB guidance using
calibrated tangent rays. It takes the strongest usable public target per cell,
converts slant range at that cell center to an axis-depth hypothesis and uses a
fixed4m scale. Missing/merged cells remain zero inputs. There are2,312 used cells
and9,976 missing cells (81.18%), with three noisy normalized overflows clipped.
Upstream's reference-depth-dependent10/20/40m normalization was not used. These
are substantial transfer-domain differences, not an identity with its training
input or a test of every video-depth method.

Common RGB/ToF coverage is135,000/230,400 native image pixels (58.59%). The
visible target portion inside it is100% for rods/boundary,77.39% for BODY and
98.27% for HEAD. Full visible targets remain the main denominator; conditional
common-FOV coverage is also reported. Nonpositive/invalid raw outputs cannot be
interpolated into valid depth. Outside coverage remains UNKNOWN. Thus the poor
rod result is not explained by cropping rods out of evaluation.

The causal dense output agrees within0.12m with3,018/3,056 returned corridor
samples inside RGB;137 other corridor samples are outside RGB. These are dense
depth diagnostics only, not exact native support retention or full-surface
coverage. All original raw ToF slots and Radar inputs remain available to the
unchanged mainline. No dense estimate was allowed to suppress another branch.
Native per-return Radar ownership is still unavailable in this capture contract.

## Post-outcome thin-object diagnosis

The separate48-frame rod audit is explanatory, not a new selection criterion:

- 24 current frames contain usable selected ToF returns from the rod. They contain all
  151 recovered temporal columns (151/248 versus repeated-current156/248).
- The other24 current frames have no usable rod ToF return; neither arm recovers any of
  their175 visible rod columns. Temporal RGB did not supply the missing surface
  in this fixed model/adapter. This does not prove the information is fundamentally
  absent or that another architecture cannot use it. This classification does
  not assert that the whole preceding prefix lacks a rod return.
- Strongest-slot selection omits some valid rod-support slots in seven frames,
  but never removes all usable rod evidence from a frame. It does not explain
  the24-frame zero-recovery stratum by itself.
- At128 angular resolution, native visible rod masks span1–5 sampled columns
  (median3);15/48 have at most two. At256 the median is6 and none have at most
  two. This is projected-mask sampling evidence, not a tested256 model or proof
  that more RGB samples improve final depth. A sampled column here has at least
  one bilinear mask value>=0.5, distinct from the depth-recovery criterion.
  No such successor was run.

Fixed qualitative examples select the last frame of the first episode in each
family, without choosing a favorable outcome. The saved comparison shows coarse
depth regions extending beyond thin native silhouettes and low-depth artifacts
around missing input regions. This suggests useful next input/model questions;
it does not establish a unique cause or rescue the completed negative control.
