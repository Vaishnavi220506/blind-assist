# MZ154: preserve finer RGB samples without increasing ToF resolution

EXPLORE Development, 2026-09-16. MZ153's fixed128 pretrained transfer is closed
as a negative control. Its post-outcome diagnostic found15/48 rod frames only
1–2 columns wide in the angular guidance grid, and no recovered columns in24
frames lacking a current usable rod return. This is one focused follow-up on
the lost RGB sampling detail, not a threshold repair or a claim that resolution
is the unique cause. Keep the fixed RGB+8x8 ToF+Radar+IMU hardware budget.

## Fixed comparison

Use the same official frozen DVSR weights and existing MZ153 runtime. Set the
generator's nonlearned scale from16 to32 so unchanged8x8 depth is repeated to
the internal64x64 feature grid and256x256 RGB is accepted. All learned parameters,
two hourglasses, four propagation passes and the repaired mirror-flow behavior
remain. This changes the network's spatial computation and effective angular
receptive field; a comparison with128 alone would not identify finer RGB detail.

Therefore run two new arms at the SAME256 model scale:

1. `direct256`: calibrated angular RGB sampled directly from original640x360.
2. `upsampled128`: the exact MZ153128 RGB guidance bilinearly enlarged to256.

Both use identical original8x8 depth arrays, strongest valid slots, missing-zero
encoding, fixed4m normalization, past/current episode prefixes and last-output
selection. No new depth samples, future frames, range fitting or model training.
Reuse the sealed MZ153 causal128 arm as a disclosed prior comparator, without
rerunning or reopening its recipe. First frames duplicate current in both arms.
The two new arms are evaluated on the same native pixels inside the old128
common-FOV mask, so a wider border footprint cannot create the gain. Propagate
finite-positive raw validity before interpolation; UNKNOWN cannot become free
space. Dense hypotheses do not veto the retained raw ToF/Radar branches.
