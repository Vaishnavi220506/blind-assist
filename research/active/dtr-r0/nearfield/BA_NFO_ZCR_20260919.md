fails three of the four user targets. More strongly, monotonicity proves no

## Frozen experiment

Use the original trained NFO checkpoint, all parameters frozen, eval mode,
original sigmoid followed by ordinal cummax; read the 2m score only. Subtract
the median of every complete calibrated ToF zone at 192x256. Even-size medians
average the two central values. Include every pixel in each median, including
evaluator-UNKNOWN pixels; no truth, area fraction or public-return gate enters
the readout. All 64 zones, including missing returns, participate. Outside
the original central-80% ToF coverage, keep the original .081 decisions.
Residuals are signed scores, not probabilities or a new four-head depth model.

There is no training. Keep the original 500 validation / 500 test frame
identities and actual realized ToF returns. The test families are training-unseen
but repeatedly consumed synthetic Development, not fresh confirmation.
The one global residual cutoff uses the original validation objective: maximize
mixed IoU at recall >=95%, using exact distinct residual values and atomic ties.
An equal-IoU tie chooses the lower cutoff. Calibration is saved and hashed before
test inference; test labels never select the cutoff or medians.

Validation chooses **-0.1943482756614685**, yielding recall95.009% / IoU43.768%,
versus original95.0004% /51.160%. Purely positive residual thresholds cannot be
presumed to preserve regions with extensive near support. The measured negative
working point admits nearly every pure-far pixel. No second threshold is tried.

At the sealed cutoff c0, test mixed recall94.285% is already below94.5%, while
pure-far FP9,876,975 already exceeds157,187. For any cutoff c>=c0, recall cannot
increase; for c<=c0, FP cannot decrease. Thus **every** global cutoff fails at
least one of these two constraints. This is a certificate from one working point,
not a test threshold sweep or a new adopted working point.

## What the result establishes

Far-small AP increases substantially, so the experiment does not demonstrate
that all local margins are too weak. Subtracting a constant preserves ranking
inside a zone, but changes ranking between zones and removes the absolute zone
level. A mostly-near zone and a mostly-far zone can both have residuals around
zero; the full-zone median is not necessarily a background estimate in a
near-dominated zone. This mechanism explains why useful relative ranking alone
does not supply the requested jointly accurate near mask.

Far-small recovers all4,213 old misses but loses36 old TP, adding140,257 FP
and removing2,561. Mixed loses28,960 TP while rescuing26,681. Pure-far adds
9,721,580 FP and removes1,792. This is broad overprediction at the chosen
working point, not successful small-support localization.

Close the current score-calibration/readout iteration as requested. Any future
experiment must address spatial evidence with its own explicit scope; this run
does not prove all spatial information or every possible representation fails.
No successor starts automatically. Downstream direction is deferred until the
mask is useful: fixed image-center / left / right sectors as requested, without
a body-coordinate reconstruction. No risk-sector integration or alert claim
is made by this mask experiment; that user direction supersedes the earlier
3D corridor proposal for the next direction readout.
