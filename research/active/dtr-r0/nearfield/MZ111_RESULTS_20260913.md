## Mechanism and task timing

Spatial hypotheses retain every angularly compatible region, but only mutual
unique pairs refine an alert. Missing ToF is no longer a mandatory association
failure. A camera-facing plane is compared with the old constant radial shell;
both are approximations to object extent. The range filter integrates measured
Doppler and current measured range, resets large innovations and requires
unique IMU-compensated visual correspondence. It does not infer a true plane
normal or calibrated certainty from its variance state.

Temporal continuation is an additive contrast on nominal. It propagates a past
measured range by Doppler for at most0.5s and requires a current RGB region with
unique correspondence. Current ambiguous Radar is not treated as a missing
packet. Visual updates never refresh range lifetime. Missing RGB, ambiguity,
stale time and invalid IMU break the chain. These assumptions need more varied
motion tests; static-source improvement alone cannot prove Doppler is essential.

Nominal and combined both detect all22 positive event segments. Mean first
correct alert delay among those events is0.0341s versus0.0227s; both maxima0.25s.
False alert segments fall20 to17 while false-alert bin duration rises8.0 to9.0s.
Fewer segments with longer false support is not an unqualified nuisance gain.
Durations count0.25s per sampled frame, not natural-route timing or user burden.
