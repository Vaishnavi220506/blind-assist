## Unique fixed rule

Filter hypotheses by exact initial observed range-bin equality. For each of the
four existing0.12m actions, partition that set by **predicted** next observations
from the already saved public forward-model bank. Minimize, lexicographically:

1. Positive hypothesis count in groups containing both positive and negative
   query hypotheses (positive unresolved mass, uniform prior enumeration).
2. Total hypothesis count in those mixed groups (total UNKNOWN mass).
3. Fixed action order +X,-X,+Z,-Z.

No pair-split term, fitted weight, threshold, scene ID or outcome-aware override.
An empty candidate set uses +X deterministically and cannot become a negative
prediction. The selector accepts only initial observation and public prior.
Public hypothetical-state labels are permitted; true-scene labels are not.

The candidate receives the same initial observations. Seal all653 choices and
their dependencies before parsing true source geometry for the selected actual
second-observation simulator. Generate only that selected next view per case;
never expose all actual future views to selection. Seal all predictions before
joining evaluator truth or old-policy outcomes. Preserve hashes of old files
before and after. Record pipeline stage order and copy exact new source/test/
protocol bytes before execution.

All moving policies use two observations and one0.12m translation. Fixed and old
adaptive comparisons use their authenticated saved predictions from the original
pilot; do not rerun or alter those policies. No extra views or motion are free.
This ideal known-pose scalar ray model is not actual ToF, real movement or device
latency. CPU `TASK_NOT_GPU_SUITABLE` small scalar operations only.
